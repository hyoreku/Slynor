# Slynor для Android

Офлайн-плеер для Android 8 и новее. Открывает аудиофайлы через системный выбор и сохраняет библиотеку. Чтобы добавить все аудиофайлы из папки и её подпапок, откройте меню Slynor и выберите «Добавить папку».

- **Библиотека.** Поиск по названию, исполнителю и альбому, сортировка, избранное и сведения о треке. На главной странице видны текущий трек, карточки плейлистов, недавно добавленные и прослушанные треки.
- **Плейлисты.** Обложку можно выбрать при создании или поменять в редакторе. В плейлисте доступны поиск, сортировка и перетаскивание треков в ручном порядке. Нажмите «Выбрать треки», чтобы отправить подборку в другие плейлисты или убрать её из текущего. Меню «Действия плейлиста» позволяет сделать копию с обложкой.
- **Воспроизведение.** Фоновое аудио, уведомление Media3 и перемотка. Скорость, повтор и эквалайзер доступны на экране трека. Кнопка «Очередь» в его шапке открывает отдельную панель. После перезапуска плеер восстанавливает очередь, текущий трек и позицию. Воспроизведение возобновляется по нажатию кнопки.
- **Звук.** 10-полосный эквалайзер с предусилением, готовыми и своими пресетами. Спектр воспроизводимого звука в виде столбцов или линии.
- **Оформление.** Светлая, тёмная и системная темы, цвет акцента, свои обои, обложки из тегов и полноэкранный плеер. На широком экране обложка и управление расположены рядом.
- **Резервная копия.** В настройках можно сохранить ZIP с плейлистами, обложками, избранным и настройками. На другом устройстве сначала добавьте исходные аудиофайлы в библиотеку. После восстановления приложение покажет количество записей, для которых нужен доступ к файлам.

## Сборка

Нужны JDK 17 или 21, Android SDK 36 и Build Tools 36.0.0. Укажите путь к SDK в `ANDROID_HOME` или откройте папку `android` в Android Studio.

```bash
./gradlew :app:lintDebug :app:assembleDebug
```

В Windows используйте `gradlew.bat`. Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions сохраняет артефакт `Slynor-Android-APK` и проверяет обновление с меньшего номера версии на том же ключе.

## Подпись релиза

Храните выпускной ключ вне Git и сохраните его резервную копию. Для публикации `Slynor-Android.apk` в GitHub Actions нужны четыре секрета репозитория.

- `ANDROID_SIGNING_KEYSTORE_B64` — хранилище ключа в Base64.
- `ANDROID_SIGNING_STORE_PASSWORD` — пароль хранилища.
- `ANDROID_SIGNING_KEY_ALIAS` — имя ключа.
- `ANDROID_SIGNING_KEY_PASSWORD` — пароль ключа.

В переменную репозитория `ANDROID_SIGNING_CERT_SHA256` запишите 64 шестнадцатеричных символа SHA-256 сертификата без двоеточий. CI сверяет отпечаток с APK. Без настроек подписи публикуется `Slynor-Android-debug.apk`. Выпускной APK имеет идентификатор `io.github.hyoreku.slynor` и устанавливается рядом с приложением из debug-preview.

Для локального `./gradlew :app:assembleRelease` передайте путь к хранилищу через `SLYNOR_SIGNING_STORE_FILE` и реквизиты через `SLYNOR_SIGNING_STORE_PASSWORD`, `SLYNOR_SIGNING_KEY_ALIAS` и `SLYNOR_SIGNING_KEY_PASSWORD`.

## Проверка на устройстве

Установите APK, добавьте два локальных файла и запустите первый. Проверьте перемотку, паузу, переход к следующему треку, воспроизведение с выключенным экраном и управление из уведомления. После перезапуска проверьте сохранённый плейлист с обложкой и возобновление трека с прежней позиции. Проверьте отключение наушников и файл, у которого отозван доступ.
