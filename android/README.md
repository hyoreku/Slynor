# Slynor для Android

Офлайн-плеер для Android 8 и новее. Открывает аудиофайлы через системный выбор и сохраняет библиотеку. Чтобы добавить все аудиофайлы из папки и её подпапок, откройте меню Slynor и выберите «Добавить папку».

- **Библиотека.** Поиск по названию, исполнителю и альбому, сортировка, избранное и сведения о треке. На главной странице видны недавно добавленные и прослушанные треки.
- **Плейлисты.** Создание, переименование, добавление нескольких треков, изменение порядка и воспроизведение по очереди или вперемешку. Трек можно добавить в плейлист и из библиотеки.
- **Воспроизведение.** Фоновое аудио, уведомление Media3, перемотка, настройка скорости, повтор трека или очереди и таймер сна. После перезапуска плеер восстанавливает очередь, текущий трек и позицию. Воспроизведение возобновляется по нажатию кнопки.
- **Оформление.** Светлая, тёмная и системная темы, обложки из тегов и полноэкранный плеер. На широком экране обложка и управление расположены рядом.

## Сборка

Нужны JDK 17 или 21, Android SDK 36 и Build Tools 36.0.0. Укажите путь к SDK в `ANDROID_HOME` или откройте папку `android` в Android Studio.

```bash
./gradlew :app:lintDebug :app:assembleDebug
```

В Windows используйте `gradlew.bat`. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. В GitHub Actions он доступен как артефакт `Slynor-Android-APK` после успешной сборки. APK подписан отладочным ключом.

## Проверка на устройстве

Установите APK, добавьте два локальных файла и запустите первый. Проверьте перемотку, паузу, переход к следующему треку, воспроизведение с выключенным экраном и управление из уведомления. После перезапуска проверьте сохранённый плейлист и возобновление трека с прежней позиции. Проверьте отключение наушников и файл, у которого отозван доступ.
