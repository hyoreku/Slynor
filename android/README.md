# Slynor для Android

Офлайн-плеер для Android 8 и новее. Он открывает аудиофайлы через системный выбор и сохраняет библиотеку для следующего запуска. Нажатие на трек запускает очередь в порядке библиотеки. Плеер поддерживает паузу, перемотку и переключение треков. Воспроизведение и управление из уведомления работают через Media3.

В интерфейсе есть главная, поиск по своей музыке и очередь. Нажатие на нижний плеер открывает обложку, шкалу времени и управление текущим треком. Для новых файлов плеер читает название и исполнителя из тегов, когда они доступны.

## Сборка

Нужны JDK 17 или 21, Android SDK 36 и Build Tools 36.0.0. Укажите путь к SDK в `ANDROID_HOME` или откройте папку `android` в Android Studio.

```bash
./gradlew :app:lintDebug :app:assembleDebug
```

В Windows используйте `gradlew.bat`. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. В GitHub Actions он доступен как артефакт `Slynor-Android-APK` после успешной сборки. APK подписан отладочным ключом.

## Проверка на устройстве

Установите APK, добавьте два локальных файла и запустите первый. Проверьте перемотку, паузу, переход к следующему треку, воспроизведение с выключенным экраном и управление из уведомления. После перезапуска откройте трек из сохранённой библиотеки. Проверьте отключение наушников и файл, у которого отозван доступ.
