# Этап 15 — обложки, оформление, миниплеер, настройка звука

## Запуск и обновление

Это исходники Windows-приложения, не готовый EXE/MSI. Закройте старое приложение через «Выйти». Сделайте резервную копию `%LOCALAPPDATA%\OwnPlayerMusic` и предыдущих исходников. Распакуйте обновление в отдельную папку, не копируйте старые JS/CSS поверх новых. Музыка и настройки хранятся вне исходников и не удаляются установщиком.

**Один установочный вход:** в PowerShell из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL.ps1
```

Параметр действует только на этот процесс PowerShell; системную политику скрипт не меняет. Перед выполнением можно открыть INSTALL.ps1 в редакторе. Нужен интернет; возможны обычные запросы установщиков Windows. Скрипт не получает права администратора автоматически.

INSTALL.ps1 проверяет/устанавливает через winget Python 3.13 x64, VLC, WebView2 Runtime и FFmpeg. Создаёт `.venv` для приложения и `.providers` для spotDL/SCDL/yt-dlp, устанавливает requirements, проверяет импорты, создание LibVLC и версии FFmpeg/ffprobe. Изолированные версии зависимостей не конфликтуют с GUI. `.providers` подхватывается приложением автоматически; `OWNPLAYER_PROVIDER_PYTHON` может переопределить путь.

Если App Installer/winget отсутствует — установите его из Microsoft Store или поставьте системные компоненты вручную и запустите `INSTALL.ps1 -SkipSystem`. Ошибка останавливает установку и показывает неуспешную команду. Исправьте причину и повторите. При нестандартной установке VLC x64 проверьте доступность libvlc.dll; скрипт рассчитан на стандартную папку VLC. Проверка запуска/импортов не доказывает доступность интернет-каталогов или отсутствие всех ошибок WebView2.

Запуск после установки — **START.cmd**. Либо:

```powershell
.\.venv\Scripts\python.exe start.py
```

Не открывайте frontend/index.html вручную. Установщик не является упаковкой программы в EXE. Автономный офлайн-дистрибутив со всеми runtime — отдельная задача.

## FFmpeg — что сделать вручную

```powershell
winget install --id Gyan.FFmpeg --exact
```

Закройте и снова откройте PowerShell, затем:

```powershell
ffmpeg -version
ffprobe -version
```

Обе команды должны напечатать версию. Если команды не найдены: скачайте Windows release essentials с https://www.gyan.dev/ffmpeg/builds/, распакуйте, например, в `C:\Tools\ffmpeg`; в пользовательскую переменную **Path** добавьте папку, в которой реально находятся **ffmpeg.exe и ffprobe.exe**, обычно `C:\Tools\ffmpeg\bin`. Перезапустите терминал и приложение. Не добавляйте сам EXE вместо папки.

Можно явно указать FFmpeg для одного запуска:

```powershell
$env:OWNPLAYER_FFMPEG = 'C:\Tools\ffmpeg\bin\ffmpeg.exe'
.\.venv\Scripts\python.exe start.py
```

ffprobe должен лежать рядом с ffmpeg. INSTALL.ps1 запоминает найденный путь в локальном runtime_paths.json; файл не входит в архив и не содержит ключей. FFmpeg нужен для конвертации/обработки аудио загрузчиками; ffprobe — для проверки видеофона. **FFmpeg не отвечает за поиск фотографий или их загрузку.** Локальный звук воспроизводится через VLC.

## Изменения

- Цветные пятна «Сейчас играет»: больше амплитуда, случайные перемещения каждые 9–13 секунд. Движение прекращается при паузе, скрытии или системном reduced motion. Это не анализ ритма песни.
- Интернет-обложки Spotify/YouTube/SoundCloud из внешнего каталога выдаются через локальный JPEG-кэш: ограничения CDN, размера и разрешения, проверка изображения, до 300 файлов. Браузеру не нужен CORS удалённого CDN для извлечения палитры.
- Для публичных результатов без обложки — ограниченное по времени сопоставление названия и исполнителя с Spotify через spotDL, включая русское/латинское написание артиста. При отсутствии уверенного совпадения обложка не придумывается. Нужно установленное окружение загрузчиков и доступ к Spotify. Часть результатов может оставаться с заглушкой.
- Вместо одиночного `muzbomb`: отдельные подписи **Аудио: домен/сервис** и **Обложка: сервис**. Если аудио реально взято с muzbomb.net, этот домен остаётся честно указанным; обложка Spotify не превращает аудио в Spotify. Для каталога Spotify пишется «подготовка spotDL»: Spotify даёт метаданные, а не прямой аудиофайл. Точный конечный сайт, выбранный внутренним поиском spotDL, пока отдельно не отображается.
- Миниплеер 360×112 логических пикселей, минимум 320×108. Физические размеры зависят от масштаба Windows. Тема и акцент берутся из основного окна через снимок состояния, без перечитывания настроек с диска на каждом тике.
- Три фона миниплеера: по тёмной/светлой теме; обои приложения; три цвета обложки. Видео всегда без звука; в скрытом окне движение/видео останавливаются. Исходная геометрия/maximized/fullscreen основного окна сохраняется предыдущей логикой этапа 14.
- Обои основного окна: JPEG/PNG/WebP, GIF и короткое MP4/WebM. GIF — до 50 МБ, 2560×1440, 300 кадров и 30 секунд; видео — до 50 МБ, 2560×1440 и 30 секунд. Разрешённые кодеки H.264/VP8/VP9/AV1; фактическая поддержка зависит от WebView2. Для совместимости предпочитайте MP4 H.264. Не воспроизводящийся файл замените; перекодирования видео в приложении нет. GIF не требует FFmpeg. При reduced motion GIF скрывается, а не показывается застывшим кадром.
- Фоновое видео отдельным muted/loop/playsinline элементом не попадает в аудиодвижок. Обложки плейлистов остаются статическими — ограничение видео обоев не переносится на них.
- «Следующие этапы» в Настройках убрано. Разделы: Общие (окно, боковая панель, язык), Оформление (тема, акцент, эффекты, обои и миниплеер), Технические (аудиовыход, зависимости, диагностика, режим разработчика).
- Выбор аудиовыхода из списка, который возвращает VLC. Выбор сохраняется и передаётся VLC без stop/play и без перемотки. Если список недоступен, остаётся системный выход Windows. При отключённом/неработающем устройстве выберите системный и обновите список. Реальная маршрутизация требует проверки на Windows.
- Заглушка большой обложки «Сейчас играет» теперь использует тот же акцент, что и остальные заглушки.
- Навигационные иконки — внешние SVG с постоянными боксами. Карта файлов: **frontend/assets/icons/README.md**. Не все графические элементы вынесены в SVG: оставшиеся места перечислены в этом README.

## Проверка на вашем ПК

1. Установка: обе команды версии FFmpeg проходят; START.cmd открывает приложение.
2. Поиск: Spotify-результаты с обложками; при недоступном каталоге — честная ошибка/резервный источник, а не чужое фото. Добавить выбранный трек, проверить файл и обложку после перезапуска.
3. Миниплеер: текущие метаданные, светлая/тёмная тема, акцент, три фона, перетаскивание, возврат из fullscreen/maximized, отсутствие пустого низа при вашем DPI.
4. Видео/GIF: выбрать фон; проверить muted, размытие, скрытие окна и возврат. При неподдерживаемом кодеке выбрать другой файл.
5. Аудиовыход: воспроизведение, смена на наушники, следующий трек, перезапуск, отключение устройства. Проверить именно слышимый звук, не только подпись UI.
6. Боковая панель: раскрытие/сворачивание, неизменность положения иконок, подсказки и клавиатура.

Остаются внешние ограничения: ВК по-прежнему не подключена; для официального SoundCloud нужны ключи. Реальная попытка spotDL скачать аудио в этапе 14 завершилась AudioProviderError; новые обложки и FFmpeg не гарантируют, что этот запрет/сетевая ошибка исчезнут. В этом этапе проверены живые Spotify-метаданные и загрузка двух обложек, не успешная живая загрузка аудио через spotDL. Нет обещаний «все песни», оригинального/320 kbps качества или обхода ограничений сервиса.

Нативные окна, аудиоустройства, потребление RAM/GPU, задержка EQ и исчезновение всех зависаний **не подтверждены на Windows**. При повторении зависания: Настройки → Технические → Сохранить снимок диагностики; пришлите логи из `%LOCALAPPDATA%\OwnPlayerMusic\logs` и последнее действие. Ключи и cookies присылать не нужно.

## Следующий шаг после приёмки

Сначала проверить этот этап на Windows. Затем отдельно: диагностика реального сбоя spotDL/доступа к источникам; нативные аудиовыходы и сценарий зависания; упаковка подписанного дистрибутива. Не добавлять новые источники вслепую до подтверждения существующего пути.
