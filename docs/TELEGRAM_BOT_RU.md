# Локальный Telegram-бот Slynor

Бот ищет музыку через Music Service и отправляет выбранный файл в личный чат владельца. MP3 и M4A отправляются как аудио. Остальные поддерживаемые контейнеры приходят документом. Лимит Telegram для отправки через облачный Bot API — 50 МБ на файл.

## Установка на Windows

1. Подготовьте Music Service и окружение `.providers` по инструкции установки [Slynor](../README.md#запуск-на-windows). Проверьте, что выбранный источник работает и FFmpeg доступен.
2. Создайте бота через BotFather и сохраните токен в локальном хранилище. Определите числовой Telegram ID аккаунта владельца.
3. Из корня репозитория установите зависимости бота в отдельное окружение.

```powershell
py -3.13 -m venv .bot
.\.bot\Scripts\python.exe -m pip install -r requirements/bot.txt
```

В первом терминале запустите Music Service. Если плеер уже запустил работающий сервис на порту 8766, используйте этот экземпляр.

```powershell
.\.venv\Scripts\python.exe -m service
```

Во втором терминале введите токен через скрытый ввод и запустите бота.

```powershell
$env:SLYNOR_TELEGRAM_OWNER_ID = Read-Host 'Числовой Telegram ID'
$botToken = Read-Host 'Токен BotFather' -AsSecureString
$env:SLYNOR_TELEGRAM_TOKEN = [System.Net.NetworkCredential]::new('', $botToken).Password
try {
    .\.bot\Scripts\python.exe -m telegram_bot
} finally {
    Remove-Item Env:SLYNOR_TELEGRAM_TOKEN -ErrorAction SilentlyContinue
    Remove-Variable botToken -ErrorAction SilentlyContinue
}
```

Бот получает события через long polling. Для локального запуска нужны интернет и два работающих процесса. Порт Music Service доступен только на loopback.

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/help` | Список команд |
| `/search название` или обычное сообщение | Поиск по названию, исполнителю или HTTPS-ссылке на отдельный трек |
| `/settings` | Выбор каталога и формата аудио |
| `/queue` | Статус последних заданий и номера для отмены |
| `/cancel номер` | Отмена задания, которое ещё в очереди |

Чтобы получить файл, откройте карточку, подтвердите право на скачивание и нажмите «Получить». Если полный файл недоступен, попробуйте другой источник. Карточка каталога сама по себе не подтверждает наличие аудио.

Настройки, задания бота и идентификаторы отправленных файлов хранятся в локальной SQLite рядом с данными сервиса. Повторный запрос может использовать Telegram `file_id` в течение семи дней или ранее запущенную загрузку. Music Service ограничивает размер своего хранилища отдельно. При вынужденном перезапуске уже выполнявшиеся задания получают статус ошибки. Их можно повторить через карточку трека.

## Проверка на аккаунте владельца

Пройдите поиск, переключение источника, получение разрешённого MP3 и файла в исходном формате, повторную отправку и отмену задания из очереди. Затем перезапустите сервис во время тестовой загрузки и проверьте её статус. Со второго Telegram-аккаунта бот должен игнорировать сообщения.
