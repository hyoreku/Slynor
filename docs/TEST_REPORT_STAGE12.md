## Python: что покрыто

### Аудиологика/настройки (22 теста)

Прежние регрессии скорости, позиции, начала следующего трека, stale events,
перемотки, rollback, чтения/атомарной записи настроек. Добавлена проверка no-op
для идентичного EQ. **LibVLC имитируется**: эти тесты не доказывают отсутствие
прерывания настоящего звука.

### SoundCloud/HLS/import (24 теста)

Используется `httpx.MockTransport`, не настоящие аккаунт/сеть:
- нормализация/URN/публичный поиск, сохранение preview и blocked;
- переиспользование токена, документированная refresh-form;
- full HLS only: preview не применяется в качестве fallback;
- повторная проверка доступа перед открытием;
- отсутствие ключей и явный блокер ВК;
- пагинация, доступные/недоступные записи, атомарный import roundtrip;
- неполный/циклический/небезопасный импорт не сохраняется;
- повреждённый файл не перезаписывается;
- безопасные домены/HTTPS/artwork;
- вложенные HLS-сегменты и URI ключей переписываются;
- Authorization не уходит с API на CDN;
- URL из JSON stream-resolver обрабатывается без выдачи секретов клиенту;
- число активных media-сессий ограничено.

### Окна/HTTP session (21 тест)

Нативные окна/иконка **имитируются**, FastAPI проверяется через TestClient:
- close-to-tray только при доступной иконке, настройки/явный выход;
- единственное мини-окно, закрытие/разворачивание, освобождение окон/трея;
- ошибка нативного трея не оставляет приложение скрытым без выхода;
- процессный header / HttpOnly SameSite-cookie;
- нет cookie, старая cookie, cross-site Origin/fetch, недопустимый Host;
- статусы провайдеров, metadata-error вместо падения отсутствующей записи;
- HLS-сессия читается без browser-cookie, но не по угаданному handle;
- HLS-плейлист переписывается, сегмент передаётся через прокси;
- стабильная online-reference не подменяется signed remote URL в состоянии;
- stale proxy error не влияет на новую сессию.

## Браузер: новые 31 проверки

API/PyWebView **имитируются**, а временные промежуточные кадры анимаций
проверяются настоящим Chromium:
- возврат у правого края, opacity 0.6;
- промежуточная и итоговая ширина левой панели, повторный клик/отмена,
  удаление временного inline-стиля;
- обложка у каждой строки очереди и загрузка изображения;
- закрытие не ставит hidden мгновенно; завершение и отмена при открытии;
- reduced-motion немедленно закрывает панель;
- сохранены три статуса access, disabled у preview/blocked, source attribution;
- в онлайн-очередь уходят только полноценно разрешённые записи;
- возврат к онлайн-источнику и импорт с недоступными строками;
- смена источника очищает старые результаты; ВК явно показывает блокер;
- настройка трея и делегирование открытия мини нативному мосту;
- мини показывает ту же песню, меняет паузу/громкость и возвращает окно;
- native hidden останавливает опрос мини, restore возобновляет его;
- отсутствие browser JavaScript errors.

## Повторный запуск

Из корня проекта после установки требований:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Браузерные тесты требуют отдельную среду Node с Playwright/Chromium
(для работы приложения они не нужны):

```bash
node tools/test_ui.cjs
node tools/test_stage12_ui.cjs
```

При нестандартном расположении браузера — `CHROMIUM_PATH`.
Тесты создают PNG в `tests/`; эти тестовые картинки в поставку не включены.
Ни один автоматический тест не использует настоящие credentials.
