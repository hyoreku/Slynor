## Установка

1. Закрыть окно, миниплеер и старый сервер. Если предыдущая версия уже в трее,
   выбрать «Выйти», а не просто закрыть окно.
2. Скопировать исходники и `%LOCALAPPDATA%\OwnPlayerMusic` в резервную папку.
3. Распаковать архив поверх исходников. Не удалять `.venv`, музыку и папку данных.
4. Установить обновлённые зависимости (добавлены `pystray` и `httpx`):

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start.py
```

Как и раньше, необходимы VLC x64 и WebView2. Если нативный трей не запускается,
окно **не прячется без пути возврата**: закрытие завершает приложение,
а Настройки показывают недоступность трея.

## Что изменилось в интерфейсе

- Возврат к списку теперь последний элемент topbar, справа. Обычная прозрачность
  40% (opacity 0.6), при наведении/фокусе — полная видимость.
- Левая панель интерполирует настоящую ширину сетки. Фиксированный EQ, обложка
  и спектр пересчитываются вместе с ней. Повторный клик берёт текущую ширину,
  старый RAF отменяется; после анимации временное inline-значение удаляется.
- При уменьшении движения анимации не выполняются.
- В строках очереди: номер → обложка → название/исполнитель. При отсутствии
  или ошибке картинки остаётся музыкальная заглушка.
- Закрытие очереди: 200 мс смещения/исчезновения, затем `hidden`. Повторное
  открытие отменяет старый callback, который иначе мог бы скрыть новое окно.

## EQ и скорость — что реально сделано

Повторное применение **идентичного** подтверждённого EQ теперь является no-op:
нет повторного вызова фильтра или скорости. Смена только скорости по-прежнему
не переподключает EQ; UI последовательно отправляет последние выбранные значения.

API возвращает `command_apply_ms`, а панель сохраняет его в
`data-command-apply-ms`. В режиме разработчика оно добавляется к сообщению:
«Команда: … мс (не задержка звука)».

**Это время выполнения команды сервером, НЕ время изменения слышимого звука.**
Плеер не называет получение ответа от VLC «мгновенным изменением звучания».
Пресеты всё ещё применяются через LibVLC, а speedup/slowed — через `set_rate`
с отключённым time-stretch. Внутренняя перестройка/буферизация VLC остаётся.

Реальный провал при переключении скорости остаётся открытой задачей. Не
внесены непроверенные «лечения» перезапуском песни, искусственной перемоткой
или резким уменьшением аудиобуфера. Следующий аудиошаг:

1. На целевой Windows записать версию VLC, формат/частоту трека, устройство
   вывода, включённость EQ/спектра и `command_apply_ms`.
2. Отдельно измерить изменение EQ и `set_rate` на непрерывном тестовом тоне.
   Сравнить со спектром включённым/выключенным и с несколькими форматами.
3. Если пауза именно в LibVLC rate-change, прототипировать отдельный постоянный
   PCM/DSP-тракт со сглаживаемым resampling и живым EQ, а не обещать бесшовность
   очередным вызовом того же API. Это отдельная миграция, требующая Windows-тестов.

## Трей и миниплеер

В Настройках → Трей и миниплеер есть «Закрывать окно в системный трей» и явный
«Выйти из приложения». По умолчанию close-to-tray включён, но используется
только если иконка действительно готова. Настройка — отдельный boolean
`close_to_tray` в прежнем `settings.json`; остальные поля сохраняются.

Меню трея:
- Открыть OwnPlayerMusic (также действие по умолчанию).
- Миниплеер.
- Пауза / Продолжить.
- Следующий трек.
- Выйти.

Кнопка ▣ в верхней строке открывает небольшое окно поверх других окон.
Оно показывает текущую песню/обложку/время и управляет предыдущим/следующим
треком, паузой, стопом и громкостью **того же** AudioEngine. Другой аудиодвижок
не создаётся. ↗ возвращает полное окно; закрытие миниплеера также возвращает его.
Нативное меню трея и миниплеер в этой поставке используют русские подписи.
Основные новые надписи полноразмерного UI включены в RU/EN-каталог;
служебные ошибки провайдера могут оставаться русскими.

При скрытии главного окна посылается native-window-state: спектр и декоративный
RAF освобождаются прежним lifecycle. Миниплеер не рисует спектр. RAM/GPU
на Windows **не измерялись**, «почти нулевой расход» не обещается.

## SoundCloud — настройка собственных ключей

Текущая официальная документация требует регистрации приложения и `client_id`
с `client_secret`; на момент проверки для получения ключей указан Artist Pro.
Client Credentials разрешает публичные поиск, воспроизведение и resolve,
но не даёт доступа к приватным данным пользователя.

Источники:
- https://developers.soundcloud.com/docs/api/guide.html
- https://developers.soundcloud.com/docs/api/register-app
- https://raw.githubusercontent.com/soundcloud/api/master/openapi/api.yaml

**Не присылайте секрет в чат и не вставляйте его в исходники.** В приложении
нет извлечения токенов из браузера или использования чужого client_id.

Для персонального запуска с собственными ключами:

```powershell
.\.venv\Scripts\python.exe tools\start_with_soundcloud.py
```

`client_secret` вводится в скрытом локальном prompt. Скрипт передаёт ключи
дочернему процессу через окружение, не пишет JSON/логи/аргументы запуска и
не сохраняет их между запусками. Альтернатива — окружение
`SOUNDCLOUD_CLIENT_ID` / `SOUNDCLOUD_CLIENT_SECRET` либо уже выданный
`SOUNDCLOUD_ACCESS_TOKEN`. Один внешний токен без ключей автоматически
продлевать нельзя; при истечении потребуется новый вход.

Не распространять собственный confidential client_secret вместе с EXE.
Для публичной поставки требуется согласованная с провайдером схема выдачи
доступа/серверная часть, а не встроенный общий секрет.

### Поиск и воспроизведение

Раздел «Поиск музыки» слева → SoundCloud → запрос. Первая версия показывает
первые 40 результатов запроса; это не выгрузка всего каталога. Результаты сохраняют
все возвращённые записи и явно показывают:
- `playable` — полное аудио разрешено;
- `preview` — только превью, кнопка воспроизведения выключена;
- `blocked` — недоступно, кнопка выключена;
- `unknown` — доступность не подтверждена, кнопка выключена.

Перед открытием потока сервер **повторно проверяет** текущее `access`.
Используются `hls_aac_160_url` / `hls_mp3_128_url`; `stream_url` и
`preview_mp3_128_url` не используются для подмены полного воспроизведения.
Под каждым треком — имя uploader и ссылка с официальным неизменённым логотипом
SoundCloud. Логотип также виден в экране онлайн-поиска, текущего онлайн-трека
и миниплеере; используется белый официальный asset на чёрной подложке. Правила:
https://developers.soundcloud.com/docs/api/buttons-logos . Перед публикацией
нужна повторная проверка актуальных требований/термов провайдера.

VLC получает localhost HLS-прокси. OAuth остаётся на Python-стороне и
отправляется только `api.soundcloud.com`, не CDN. Перенаправления, HLS-вложенные
плейлисты/сегменты/ключи валидируются по HTTPS и allowlist `sndcdn.com` /
`api.soundcloud.com`; URI переписываются в ограниченные случайные локальные
сессии. Audio chunks передаются потоково, аудиофайлы не записываются на диск.
Ошибки активного прокси показываются в состоянии плеера; старые сессии не
должны менять ошибку нового трека.

**Проверки на настоящем аккаунте ещё нет:** без ключей невозможно подтвердить
текущий ответ API, авторизацию полного HLS и воспроизведение VLC на Windows.
Сеть, география, права автора и тариф могут сделать трек недоступным.

### Импорт

Вставить публичную HTTPS-ссылку SoundCloud на плейлист → Импортировать.
Сохраняются имя, обложка, источник, метаданные и список записей в
`%LOCALAPPDATA%\OwnPlayerMusic\online_playlists.json`, отдельно от локальных
плейлистов. Preview/blocked остаются в списке; проигрывание идёт по разрешённым
записям. Это **не скачивание аудио**.

Пагинация обрабатывается до конца. Если API вернул меньше записей, чем заявлено,
нет идентификатора записи, обнаружен цикл или превышен лимит 5000 записей,
частичный импорт не выдаётся за полный и не сохраняется. Повреждённый файл
не перезаписывается. Лимит этой первой версии: 100 импортированных плейлистов.
Редактирование/удаление/синхронизация онлайн-импортов — следующий этап.

## ВК Музыка — явный блокер

Выбор ВК виден в интерфейсе, но **это не готовое подключение ВК**.
Поиск/импорт возвращают явную недоступность. В проверенной публичной
документации не удалось подтвердить официальный audio-search/полное аудио
для этого приложения; https://dev.vk.com/ru/method/audio.search вернул 404.
Это не доказательство отсутствия любых партнёрских возможностей ВК.

Чтобы реализовать ВК, нужен подтверждённый официальный/партнёрский доступ с
документацией, разрешениями и допустимой авторизацией. Чужие токены приложений,
подмена user-agent и сбор cookies не добавлены. Если такого доступа нет,
требование обоих источников остаётся **невыполненным**, а не маскируется
перенаправлением на сайт.

## Локальная безопасность

API команды требуют случайную сессию текущего процесса. /ui и /mini выдают
HttpOnly SameSite=strict cookie; нативный трей использует процессный header,
не вставляя секрет в JS или URL. Cross-site origin/fetch и неподходящий Host
отклоняются. HLS исключён из cookie-проверки только по непредсказуемому
ограниченному media-handle, чтобы его мог читать VLC. Токены провайдера и
подписанные удалённые URL не возвращаются в metadata JSON и не сохраняются
в импорт. API слушает прежний 127.0.0.1, access_log выключен.

Эта защита не изолирует приложение от вредоносного процесса того же пользователя.

## Приёмка на Windows и следующий порядок

1. Установить зависимости и проверить старую локальную библиотеку, EQ,
   остановку, паузу, перемотку, формы/обои/RU-EN.
2. Подтвердить оба направления анимаций и очередь с настоящими обложками.
3. Закрыть в трей, открыть снова, открыть/закрыть миниплеер, менять громкость,
   выйти из трея: сервер/окна/звук должны завершиться. Проверить отказ трея.
4. Отдельно измерить паузу VLC и выбрать аудиопрототип; задача ещё открыта.
5. С собственными ключами провести SoundCloud smoke-тест поиска, полного
   доступного HLS, preview/blocked, импорта, истечения токена и ошибок сети.
6. Для ВК получить официальный доступ либо явно согласовать, что источник
   заблокирован. Не заменять его SoundCloud-совпадениями молча.
7. Затем пользовательский OAuth/приватный импорт, управление онлайн-плейлистами,
   спектр сетевого источника, Windows 10/11, замеры ресурсов и EXE/установщик.
