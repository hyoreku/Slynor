# GUI-приёмка Slynor на Windows: 2026-10-28

Проверка выполнена на Windows 11 x64 (10.0.22631), экран 1920×1080 при масштабе 125 %,
CPython 3.13.15 x64, VLC 3.0.24, WebView2 156.0.4314.50, Deno отсутствует.

Метод: пользовательские данные (library.json, playlists.json, settings.json, музыка в Downloads)
скопированы в изолированный `LOCALAPPDATA`, пути внутри JSON перенаправлены на копию. Запускался
настоящий `start.py` с реальным окном pywebview/WebView2; управление — через локальный API
с process-local токеном, кнопки интерфейса — через UI Automation, снимки — через Win32.

## Чего это не доказывает

- **Слышимый звук.** Аудиоконвейер подтверждён состоянием LibVLC, декодированным PCM для спектра
  и списком устройств, но вывод на колонки ушами не проверялся.
- **Установщик.** Inno Setup отсутствует, `dist/installer` не пересобирался; установка, обновление
  и удаление с сохранением данных не проверены.
- **Физический офлайн.** Сеть не отключалась: недоступность имитирована мёртвым прокси.
  Провайдеры и онлайн-поиск не проверялись, живой эксперимент остаётся отдельной задачей.
- **Чистая VM.** Приёмка шла на рабочей машине с установленными VLC/WebView2/FFmpeg.

## Как повторить

1. Скопировать `%LOCALAPPDATA%\OwnPlayerMusic` во временную папку и перенаправить пути в JSON.
2. Запустить `start.py` с `LOCALAPPDATA=<копия>`; токен API берётся из того же процесса.
3. Управлять воспроизведением через `/api/player/*`, окнами — через `/api/desktop/*`.
4. Кнопки интерфейса искать через UI Automation (WebView2 требует `--force-renderer-accessibility`),
   снимки делать после `SetProcessDPIAware`, иначе при масштабе 125 % координаты смещаются.
5. Для офлайн-проверки задать `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` на закрытый порт.
