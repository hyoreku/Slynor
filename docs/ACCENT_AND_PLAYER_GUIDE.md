# Этап 5: акцентный цвет и нижняя панель только при выбранной песне

## Установка
1. Полностью закрой приложение и останови отдельный сервер, если он работает.
2. Сделай резервную копию проекта: архив заменяет исходники, в том числе CSS.
3. Перенеси содержимое архива в существующий корень проекта с заменой файлов.
   desktop.py и start.py должны быть рядом; backend и frontend совпасть с
   существующими каталогами. Не создавай дополнительный вложенный корень.
4. Не удаляй .venv и %LOCALAPPDATA%\OwnPlayerMusic. Библиотека/плейлисты остаются.
5. Новых зависимостей и React нет. Запусти:

```bash
./.venv/Scripts/python.exe start.py
```

## Новое поведение плеера
- При запуске без песни панели внизу нет. Её элементы не доступны клавишей Tab.
  Центр и боковая панель занимают освобождённое место.
- Первую песню запускай из «Моя музыка» или плейлиста кнопкой ▶ у строки.
  Для пути вручную есть «Файл и диагностика → Запустить файл».
- Когда сервер сообщает о выбранном файле, панель появляется.
- Пауза сохраняет файл и очередь, панель остаётся с кнопкой продолжения.
- Кнопка ■ «Стоп» останавливает VLC, снимает текущую песню и очищает очередь.
  Панель скрывается, открытая очередь закрывается.
- Библиотека и плейлисты не очищаются. Громкость и выбор случайного режима
  сохраняются в текущем сеансе для следующего запуска песни.
- Новый запуск песни снова формирует очередь из полного выбранного списка.
- Удаление записи из библиотеки/плейлиста не снимает уже играющую песню.
- Если чтение/воспроизведение выбранной песни завершилось ошибкой, панель
  остаётся доступна для остановки и выбора другой песни.
- Потеря связи не скрывает панель сама по себе: это не команда «Стоп».

Короткая CSS-анимация .22 с применяется только при появлении панели.
При prefers-reduced-motion она отключена. Скрытие после Стоп происходит сразу.

## Настройки цвета
1. Открой «Настройки».
2. Выбери готовый оттенок или нажми квадратик «Свой цвет».
3. Цвет меняется сразу как предпросмотр, ещё без записи на диск.
4. Нажми «Сохранить цвет» — только после этого выбор сохранится на перезапуск.
5. «Вернуть фиолетовый» возвращает предпросмотр исходного цвета. Чтобы
   сохранить этот возврат, также нажми «Сохранить цвет».
6. Если ничего не изменилось, кнопка сохранения недоступна.

Акцент меняет основные кнопки, выделение, ползунки, иконки, границы и некоторые
декоративные заливки. Общий тёмный фон и нейтральные поверхности остаются.
Светлая тема и пользовательские обои — отдельные последующие этапы.
Текст на цветных основных кнопках автоматически чёрный или белый в зависимости
от яркости фона. Для небольших цветных надписей используем более светлый оттенок.

## Хранение и ошибки
%LOCALAPPDATA%\OwnPlayerMusic\settings.json

Формат текущего этапа: version=1, accent="#RRGGBB". Нет файла — фиолетовый
по умолчанию. Не редактируй файл вручную во время работы приложения.
Сохранение цвета не меняет library.json, playlists.json и обложки.

При ошибке записи предпросмотр остаётся на экране, но появится сообщение,
что он не сохранён. Ранее сохранённый цвет не заменяется.
Если settings.json повреждён, цвета не разрешается сохранять поверх него.
Для восстановления: закрой приложение, сделай копию файла и переименуй
settings.json в settings.backup.json, затем запусти приложение. Загрузится
фиолетовый по умолчанию. Другие файлы данных не трогай.

## Где что находится
- player/audio_engine.py: stop() очищает текущую песню и очередь, get_state()
  возвращает idle и нулевое время, когда песни нет.
- frontend/index.html: footer player-bar изначально hidden;
  экран настроек содержит палитру, свой цвет и кнопки сохранения/возврата.
- frontend/js/app.js: setPlayerVisible() показывает/скрывает панель;
  playbackRevision отбрасывает устаревшие ответы состояния после команд;
  applyAccent() меняет CSS-переменные; initializeSettings()/saveAccent()
  читают/сохраняют через Python-мост; previewAccent() не пишет на диск.
- frontend/css/styles.css: раздел 12 управляет пустой строкой сетки и анимацией;
  раздел 13 оформляет палитру; цвета связаны с переменными :root.
- desktop.py: load_settings()/save_settings() и приватная проверка JSON.

## Самостоятельное упражнение
В styles.css найди правило:

```css
.player-bar:not([hidden]) { animation: player-appear .22s ease-out; }
```

Поменяй .22s на .35s, сохрани и перезапусти. Плеер появится немного медленнее.
Не делай анимацию слишком долгой: кнопки должны быстро становиться доступны.
Можно удалить animation из этого правила, если анимация не нравится.

## Проверка у себя
- При запуске панели нет, свободное место занимает интерфейс.
- Запуск песни показывает панель, пауза её не скрывает.
- Стоп скрывает и убирает текущий трек/очередь, но не музыку из библиотеки.
- Повторный запуск возвращает панель и полноценную очередь.
- Цвет меняется сразу; после сохранения и перезапуска остаётся.
- Предпросмотр без сохранения не меняет цвет на следующем запуске.
- В маленьком окне нет горизонтальной прокрутки.

Следующий этап: собственные обои с сохранением копии, затемнение, размытие и сброс.
