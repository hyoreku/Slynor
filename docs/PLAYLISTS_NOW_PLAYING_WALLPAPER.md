# Этап: карточки плейлистов, «Сейчас играет» и обои

## Обновление без потери данных
1. Закрой приложение и останови старый отдельно запущенный сервер (Ctrl+C).
2. Сделай резервную копию исходников; для дополнительной страховки скопируй `%LOCALAPPDATA%\OwnPlayerMusic`.
3. Распакуй архив в корень существующего проекта с заменой исходников. Не удаляй `.venv` и папку данных приложения.
4. Запусти из корня:
   ```bash
   ./.venv/Scripts/python.exe start.py
   ```
Новых зависимостей относительно предыдущего этапа нет. Pillow, Mutagen, VLC остаются нужны.
После изменения Python приложение надо перезапустить, здесь нет автоматического reload.

## Плейлисты
- По умолчанию квадратная **обложка**, название и число песен под ней. Вся карточка открывает плейлист.
- Прежних кнопок под обложкой нет. Карандаш справа сверху появляется при наведении или фокусе клавиатуры. На сенсорных устройствах виден постоянно.
- Карандаш открывает правую панель: название + «Сохранить название», выбор/сброс обложки, удаление с подтверждением.
- Панель закрывается крестиком, Escape или нажатием на затемнённую область. Tab остаётся внутри панели.
- Изменения обложки применяются сразу, отдельно сохранять её не нужно. При ошибке введённое название не стирается.
- Удаление плейлиста не удаляет файлы и не обрывает уже созданную очередь.
- Настройки → Форма обложек → Широкие обложки — как раньше → «Сохранить форму».
  Возвращаются прежние **пропорции** обложки, но не прежний ряд кнопок: управление остаётся в панели.

## Сейчас играет
- Успешный запуск песни из списка или ручного пути открывает отдельный экран после ближайшего опроса состояния (обычно до секунды).
- В центре ограниченная по размеру обложка из метаданных, под ней название и исполнитель. Без картинки — символ ноты.
- Обложка не окрашивает фон. Собственные обои пользователя, если выбраны, остаются общим фоном приложения.
- Кнопка справа «К списку песен →» возвращает в текущий список, сохраняя выбранный плейлист, поиск и сортировку; воспроизведение продолжается.
- Нажатие на мини-обложку в нижнем плеере вновь открывает этот экран.
- Автопереход к следующей песне обновляет картинку/название, но не выбрасывает пользователя из списка или настроек.
- Пауза сохраняет экран и нижнюю панель. Стоп снимает песню, очищает очередь, скрывает нижнюю панель и возвращает из «Сейчас играет» в список.
- Источники обложек не менялись: локальные файлы — встроенные метаданные; онлайн-обложки добавим вместе с официальным API музыкального провайдера.

## Собственные обои
Настройки → Собственные обои.
- «Выбрать изображение» открывает системный диалог JPG/PNG/WEBP. Отмена ничего не меняет.
- Пределы: 20 МБ, 40 млн пикселей. Создаётся JPEG-копия максимум 2560×2560, с сохранением пропорций и учётом EXIF-поворота. Без увеличения маленькой картинки и без переноса EXIF. Прозрачность накладывается на тёмный фон.
- Копия сохраняется **сразу**, в `%LOCALAPPDATA%\OwnPlayerMusic\wallpapers`.
- Затемнение 0–90%, размытие 0–30 px видны сразу. Нажми «Сохранить эффекты», чтобы оставить их после перезапуска.
- Выбор другого изображения загружает ранее сохранённые эффекты; несохранённый предпросмотр эффектов не переносится на новую картинку. Отмена выбора сохраняет и предпросмотр.
- «Сбросить обои» сразу убирает копию и возвращает эффекты к 65% / 0 px. Цвет и форма карточек не сбрасываются.
- Под интерфейсом остаются тёмные подложки ради читаемости. 0% затемнения не означает прозрачные кнопки/панели.
- Пропорции фонового изображения сохраняются, края могут обрезаться по размеру окна (cover), редактора кадрирования пока нет.
- Если управляемую копию удалили вручную, используется обычный фон и выводится сообщение. Выбери изображение заново или сбрось обои. JSON самовольно не переписывается.
- При сбое записи новая копия удаляется, старая ссылка/картинка сохраняются. В случае аварийного завершения процесса до записи JSON возможен неиспользуемый файл; автоматической уборки после аварии пока нет.

## Где менять код
- `frontend/index.html`: `screen-playing`, `playlist-editor`, `wallpaper-layer`, блоки настроек.
- `frontend/js/app.js`: `renderPlaylists` создаёт карточки. Раздел 14 — редактор, 15 — «Сейчас играет», 16 — форма и обои.
- `frontend/css/styles.css`: разделы 14–17 отвечают за новые компоненты и адаптацию; исходные разделы 1–13 сохранены.
- `desktop.py`: чтение/валидация настроек, атомарная запись, выбор и сброс обоев.
- `backend/wallpaper_assets.py`: проверка, уменьшение и хранение JPEG-копий.
- `backend/main.py`: `/api/assets/wallpapers/{filename}` — только безопасные имена в папке обоев, не доступ ко всей AppData.
- `settings.json`: сохраняются `accent`, `playlist_shape`, `wallpaper`, `wallpaper_dim`, `wallpaper_blur`. Старый файл только с цветом поддерживается; неизвестные будущие поля не стираются.

К новым смысловым блокам добавлены комментарии на русском. React и сборщик не требуются.

## Проверка на твоём компьютере
1. Открой плейлист по карточке; затем вернись на главную и измени его название/обложку через карандаш.
2. Запусти песню с обложкой и без неё, вернись к списку справа, вновь открой экран через мини-обложку.
3. Проверь паузу, следующий трек и Стоп; при Стоп нижняя панель должна исчезнуть.
4. Сохрани широкую форму, цвет, обои и эффекты, перезапусти приложение — оформление должно остаться.
5. Сбрось обои — исходное изображение на диске должно остаться.

В среде подготовки проверены Python-синтаксис 3.12, реальная обработка картинок Pillow,
метаданные Mutagen и сценарии интерфейса Chromium (1440×900, 600×400, 390×844).
Системный диалог PyWebView и реальное воспроизведение VLC под Windows здесь не запускались:
для них использовались тестовые замены, окончательная проверка — на твоём компьютере.
