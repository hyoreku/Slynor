# Этап 13 — исправления интерфейса, публичный поиск и диагностика

Это обновлённые **исходники**, не Windows EXE. Пользовательские данные остаются в
`%LOCALAPPDATA%\OwnPlayerMusic`. Новая версия не удаляет музыку и старые плейлисты.

## Установка

1. Завершить старый экземпляр через «Выйти» в системном трее. Закрыть старый сервер.
2. Сделать резервную копию исходников и `%LOCALAPPDATA%\OwnPlayerMusic`.
3. Распаковать проект в отдельную папку либо заменить исходники, сохранив `.venv`.
4. Из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start.py
```

По-прежнему нужны VLC x64 и WebView2, соответствующая разрядность Python.
Internet Archive работает без ключей. Парсеры msoc — дополнительная установка
**для Python 3.12–3.14** (для них запускать pip тем же интерпретатором):

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-search.txt
```

Без msoc приложение продолжает работать: пропускает его в автопоиске.
В режиме отдельного парсера показывает понятную ошибку установки.
Для поиска через эти парсеры ffmpeg не вызывается, их TUI не запускается.
SoundCloud использует прежние переменные `SOUNDCLOUD_CLIENT_ID` и
`SOUNDCLOUD_CLIENT_SECRET` или `SOUNDCLOUD_ACCESS_TOKEN`. Не записывайте секреты
в проект и не присылайте их в чат. **ВК не подключена**, пользовательского входа
ВК/Яндекс и снятия ограничений доступа в этой версии нет.

## Что изменено по замечаниям

1. Форма создания плейлиста получила отступы, перенос элементов и свободное место
   перед карточками. Проверяется отсутствие наложения.
2. Меню ⋯ анимирует открытие/закрытие. Окно сведений о файле закрывается с
   анимацией, включая Escape. Повторное открытие отменяет старую анимацию.
3. Главное окно вычисляет центр рабочей области монитора под курсором.
   Координаты корректируются под DPI; смешанное масштабирование мониторов
   требует приёмки на настоящей Windows.
4. Значок запуска строки плавно появляется/исчезает. Клик по названию, исполнителю
   или свободной области строки запускает её один раз. Кнопки ⋯, ссылки, элементы
   ввода и выделение текста не вызывают дополнительный запуск.
5. Системная иконка трея сохранена. Отдельный миниплеер теперь без рамки,
   по умолчанию сверху по центру, поверх окон. Перетаскивается за область названия
   и исполнителя; положение сохраняется с задержкой. «−» скрывает в трей, «↗»
   возвращает главное окно. Если трей недоступен, скрытие возвращает главное
   окно: приложение не остаётся без пути возврата. Исчезнувший монитор приводит
   к возврату в текущую рабочую область.
6. Поиск начинается после 350 мс без ввода, от двух символов, кнопка поиска убрана.
   Старое задание отменяется; результаты старого запроса не заменяют новые.
   Показаны песни и сгруппированные имена исполнителей из результатов. Это
   **не полноценные профили артистов** с дискографией/аватарами.
7. Кнопка миниплеера одна — в нижней панели рядом со случайным режимом.
8. Карточка обложки выбранного плейлиста получает мягкое свечение из трёх
   доминантных цветов изображения.
9. Обложка нижнего плеера плавно увеличивается и подсвечивается при наведении
   или клавиатурном фокусе, затем возвращается. Палитры кэшируются с лимитом.
   Если браузер запрещает чтение удалённой картинки через CORS, используется
   нейтральное оформление, а не выдуманные цвета.
10. Цветные размытые области на экране «Сейчас играет» медленно двигаются.
    Это декоративное движение, **не аудиореактивный спектр**. Оно останавливается
    при паузе, скрытии окна, переходе с экрана и при reduced-motion.
11. Убраны синхронные `evaluate_js` из нативных событий закрытия/восстановления.
    Нативные команды выполняются последовательно в отдельной очереди; HTTP
    возвращает подтверждение принятия, не ждёт выполнения GUI. Координаты движения
    берутся из аргументов события, а не блокирующих `Window.x/y`. Видимость окна
    передаётся в состоянии плеера; в скрытом главном окне не обновляется тяжёлый UI,
    миниплеер опрашивает состояние реже. Добавлены журналы и watchdog команд окна.

Пункты о нативных окнах реализованы и проверены тестовыми двойниками, но не
объявляются подтверждёнными на Windows. Причина всех случайных зависаний пока
**не установлена**. Возможные блокировки VLC/WebView2 требуют логов и воспроизведения.
Паузы при смене скорости и слышимая задержка эквалайзера также **не объявляются
устранёнными**: не меняем рабочий аудиодвижок наугад без измерения Windows/VLC.

## Интернет-музыка: как работает

Автопоиск идёт последовательно:

1. SoundCloud, если настроены собственные ключи.
2. Hitmo, затем Muzbomb — если установлен msoc 0.3.1.
3. Internet Archive — встроенный резерв без ключей.

Если нет доступного аудио, запрашивается следующий источник. Если нашлись
воспроизводимые кандидаты, поиск останавливается; можно вручную выбрать другой
источник. Нет бесконечного перебора, автоматической загрузки чужой версии песни
или обещания найти любой трек. Результат выбирает пользователь. Если ссылка
устарела/не отвечает, повторите поиск или смените источник.

Парсеры работают в отдельном процессе с лимитом времени: 7 секунд внутри,
жёсткое завершение около 9 секунд снаружи. Ключи SoundCloud не передаются этому
процессу. Неподдерживаемые CDN-ссылки отбрасываются; поддерживаются HTTPS-домены
archive.org, hitmotop.com, muzbomb.net, mp3uk.net и их поддомены. Адрес каждого
перехода проверяется. Приватные/локальные адреса отклоняются. Открытие произвольного
URL, обход DRM/подписки, извлечение токенов и скачивание закрытых каталогов не реализованы.

Живая проверка показала: **Hitmo — HTTP 403**, **Muzbomb — пустой результат**.
Это не скрывается как успешное подключение. Internet Archive вернул записи;
у выбранной записи проверен ответ `206 audio/mpeg`, прочитано 16 КБ.
Это проверка сети, не прослушивание через настоящий VLC.

Встроенный Archive-поиск ограничен несколькими записями и MP3-файлами, поэтому
выдача не исчерпывающая. Пользовательские запросы не исполняются как произвольный
синтаксис advancedsearch. Превью/blocked/unknown SoundCloud не воспроизводятся.

### Добавление и скачивание

- **«+ В список»** у публичной записи сохраняет устойчивый идентификатор потока в
  выбранный локальный плейлист или общую библиотеку. Для этого нужен интернет.
  URL хранится в `public_tracks.json`; это не аудиофайл. Лимит — 2000 закреплённых
  ссылок. Если файл повреждён, он не перезаписывается автоматически.
- **«↓ Скачать»** требует подтверждения права на скачивание. Свободная страница
  и прямой MP3 **не гарантируют разрешения правообладателя**. Для Archive есть
  ссылка на страницу записи с условиями/лицензией; их нужно проверить.
- Фоновая очередь принимает не больше четырёх заданий и качает по одному.
  Лимит — 200 МБ/файл и 120 секунд чтения. Сначала пишется `.part`; после проверки
  полноты и разбора MP3 через mutagen — атомарное переименование и добавление
  файла в выбранный плейлист/библиотеку. HTML, повреждённые и неполные файлы
  не добавляются; временный файл удаляется.
- Папка: `%LOCALAPPDATA%\OwnPlayerMusic\Downloads`. Существующие файлы не
  перезаписываются. Если запись плейлиста не удалась, сообщение показывает путь
  к уже скачанному файлу: его можно добавить обычной кнопкой «Добавить музыку».
- При закрытии приложения незавершённые задания отменяются. Автоматического
  восстановления загрузки после перезапуска пока нет. Завершённые MP3 остаются
  в Downloads. Удаление трека из списка не удаляет файл.
- SoundCloud в этой версии остаётся источником официального потокового
  воспроизведения и импорта публичных плейлистов, **не скачивания**.
  Для постоянного списка SoundCloud используется импорт плейлиста сервиса.
  Извлечение его HLS в MP3 и массовая загрузка не добавлялись.

## Если снова зависнет или закроется

Журналы: `%LOCALAPPDATA%\OwnPlayerMusic\logs`:

- `app.log` и ротации — необработанные Python-ошибки и сбои команд окна;
- `stacks.log` — стеки при фатальном сбое Python/поддерживаемой нативной ошибке,
  при ожидании нативной команды дольше 10 секунд и по кнопке в Настройках;
- предыдущий большой файл стеков переносится в `stacks.previous.log` при запуске.

Если интерфейс ещё отвечает, нажмите «Сохранить снимок диагностики» в Настройках.
Если завис целиком — подождите 10–15 секунд, затем при необходимости завершите
процесс и сохраните логи. Напишите время, последнее действие, Windows/Python/VLC,
был ли активен миниплеер и играла ли локальная песня или интернет-поток. Проверьте
логи перед отправкой: в стеках могут быть личные имена папок. Cookies, settings.json
и ключи SoundCloud присылать не нужно.

Watchdog наблюдает нативные команды окна, а не гарантированно каждое зависание
VLC/драйвера. Без воспроизведения конкретной ошибки обещать полное устранение нельзя.

## Приёмка на Windows

1. Запуск по центру, 100/125/150% DPI, повторный запуск после отключения монитора.
2. 20 циклов главное окно → миниплеер → главное; перенос миниплеера, скрытие,
   восстановление из трея и сохранение позиции после перезапуска.
3. Закрытие в трей и полный «Выйти»; при недоступном трее нельзя потерять окно.
4. Создание нескольких плейлистов, форма над карточками, сведения/Escape,
   быстрый повторный ⋯, запуск строки без двойного старта.
5. Свечение, отключение эффекта фона, пауза, скрытие, reduced-motion.
6. Быстрый набор/очистка поиска, недоступный провайдер, медленная сеть.
7. Поток Archive → пауза/перемотка/следующий; добавление ссылки, перезапуск,
   воспроизведение сохранённого потока. Не каждый сервер поддерживает Range.
8. Скачать разрешённый MP3, проверить локальное воспроизведение без сети,
   добавление в конкретный плейлист, отказ доступа к папке, обрыв соединения.
9. Standard/Speedup/Slowed на локальном WAV и MP3, начало следующей песни,
   перемотка, EQ во время игры. Отдельно фиксировать слышимую паузу.
10. Длительный прогон и измерение RAM/GPU/CPU в фоне и на экране песни.

## Следующие задачи после приёмки

1. По полученным логам воспроизвести оставшиеся блокировки; при необходимости
   вынести владение VLC в отдельный поток и измерить задержку аудиотракта.
2. Улучшить ранжирование и профили исполнителей, долговечность внешних ссылок,
   интерфейс отмены/повторения загрузки, восстановление незавершённых заданий.
3. Завершить настройку настоящего SoundCloud-приложения и проверить его API;
   для ВК сначала подтвердить доступный способ авторизации/полного аудио.
4. Windows EXE/установщик, иконка, перенос зависимостей, долгий ресурсный тест.

## Источники и ограничения библиотек

- msoc: https://pypi.org/project/msoc/ — 0.3.1, Python >=3.12,<3.15;
  https://github.com/paranoik1/msoc. Проверены код Hitmo/Muzbomb и реальный поиск.
- Internet Archive advanced search: https://archive.org/advancedsearch.php;
  метаданные: https://archive.org/metadata/MonkeysSpinningMonkeys_201610;
  проверенная запись: https://archive.org/details/MonkeysSpinningMonkeys_201610.
- Официальные возможности Jamendo изучены, но интеграция не подключалась:
  https://developer.jamendo.com/v3.0/tracks и
  https://developer.jamendo.com/v3.0/tracks/file. Нужен client_id, возможность
  скачивания определяется отдельно для каждого трека.
