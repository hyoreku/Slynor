# Приёмка этапа 21 на Windows

Это сценарий и пустой протокол, а не отчёт о пройденной проверке.

## Окружение

При закрытом Slynor запустить `CHECK.cmd`. Сохранить результат
`runtime-check.json`. Ничего не переустанавливать автоматически.

- Windows / версия WebView2: __________
- Версия Slynor: архив 21
- Масштаб Windows: __________
- Общий результат CHECK: __________

## Проверки шести исправлений

| Сценарий | Ожидаемый результат | Результат / примечание |
| --- | --- | --- |
| Библиотека и плейлист: короткие/длинные названия, нет обложки/альбома | Равные строки, промежуток 8 CSS-px, нет скачка при наведении | Не проверено |
| Настройки: начало, прокрутка, все три вкладки | Нет чёрной полосы/перекрытия; вкладки прокручиваются с секциями | Не проверено |
| Полупрозрачная тема + обои, экран библиотеки | Между sidebar, содержимым и нижним плеером нет разницы затемнения | Не проверено |
| «Сейчас играет» → пауза → возврат, при обеих ширинах sidebar | Sidebar полностью скрыт, возврат восстанавливает прежнюю ширину | Не проверено |
| EQ в трёх темах, особенно полупрозрачной | За панелью не виден текст песни или обложка | Не проверено |
| Видео/GIF: три повтора, изменение затемнения/цвета | Сохранение настроек не перезапускает фон; отдельно оценить границу самого файла | Не проверено |

Повторить в обычном и развёрнутом окне, при масштабе Windows 100% и используемом
лично вами. Проверить изменение размера при открытом EQ. На узком окне строки
выше — это ожидаемая адаптация, а не случайное расстояние.

## Продолжение плана

1. Локальная песня: пауза, продолжение, перемотка, переход далее, EQ и скорость.
   Отдельно подтвердить слышимый звук и отсутствие разрыва; наличие команды
   в API этого не доказывает.
2. Смена аудиовыхода, отключение USB и возврат к системному устройству.
3. Основное окно → миниплеер → возврат, 10 повторов. Трей → возврат, 10 повторов.
4. Если есть зависание — время, последнее действие и снимок диагностики из
   Технических настроек. Не отправлять cookies, ключи или сетевые пароли.
5. Только после успешной приёмки — `docs/BUILD_WINDOWS.md` и `BUILD_WINDOWS.ps1`:
   установка под обычным пользователем, запуск, трей, обновление и удаление
   без потери библиотеки. Подпись — отдельная операция с сертификатом.

Если пауза фона сохраняется, приложить исходный GIF/MP4/WebM и отметить:
первый запуск / каждый повтор / возврат из трея / сохранение настроек.
