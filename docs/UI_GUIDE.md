# Как разбирать интерфейс самостоятельно

1. Откройте `frontend/index.html` и найдите `.app-shell`.
2. Внутри него три области: `.sidebar`, `.workspace`, `.player-bar`.
3. Откройте `frontend/css/styles.css`, раздел 3. `display: grid` задаёт каркас.
4. `grid-template-columns` определяет левую панель и основную область.
5. `grid-template-rows` оставляет отдельную нижнюю строку для плеера.
6. `.workspace { overflow-y: auto; }` прокручивает только центр.
7. В `:root` поменяйте `--sidebar-width` с 232px на 248px, сохраните и перезапустите.
8. Верните значение, если результат не нравится. Затем попробуйте цвет `--accent`.
9. В медиа-запросах размеры переопределяются для маленьких окон.
10. Обложки пока являются заглушками; импорт пользовательских картинок — отдельный этап.

Первое задание: самостоятельно подобрать ширину панели и размер карточек,
не изменяя JavaScript. После этого переходить к компактному списку треков.

## Этап 2: компактный список треков

### Установка обновления
1. Полностью закрой приложение и останови отдельный сервер, если он запущен.
2. Сделай копию своей папки frontend.
3. Из архива обновления перенеси в проект frontend/index.html,
   frontend/css/styles.css, frontend/js/app.js. Согласись на замену.
4. Python-файлы, .venv и пользовательские данные трогать не нужно.
5. Запусти из корня проекта: ./.venv/Scripts/python.exe start.py

### Что где находится
- index.html: шапка колонок track-columns, контейнер списка library-list,
  всплывающее меню track-menu и dialog со сведениями track-details-dialog.
- app.js: renderLibrary() создаёт строки из реальных данных. Поэтому названия
  песен нельзя менять в index.html: они приходят из файлов/метаданных.
- styles.css: раздел 5 задаёт сетку, размеры строк, цвета и меню.
- openTrackMenu()/closeTrackMenu(): меню вне списка, закрытие по Escape,
  клику снаружи и прокрутке. Стрелки перемещают фокус между действиями.
- showTrackDetails(): окно только для просмотра, без изменения тегов.

### Как пользоваться
1. Открой «Моя музыка».
2. Наведи на номер слева — появится ▶. Нажми, чтобы запустить эту песню.
   Можно также выбрать кнопку клавишей Tab и нажать Enter.
3. Открой ⋯ справа. Добавление использует плейлист, выбранный сверху
   в «Добавлять песни в». Если песня уже там, этот пункт недоступен.
4. «Сведения о файле» показывает название, исполнителя, альбом, длительность,
   имя файла и полный путь. Escape или × закрывают окно.
5. «Убрать из библиотеки» убирает запись из общей библиотеки, не удаляя
   музыкальный файл и его записи в других плейлистах.
6. В открытом плейлисте пункт удаления называется «Убрать из плейлиста».
   Он не меняет общую библиотеку и другие плейлисты.
7. Уже запущенная очередь остаётся снимком списка. Для применения нового
   состава запусти песню повторно из нужного списка.
8. Альбом при ширине окна <=1100px скрыт в списке, но доступен в сведениях.
   В узком окне длительность переносится под исполнителя.

### Небольшое самостоятельное упражнение
В styles.css найди правило .library-item с min-height: 72px.
Поменяй на 80px, сохрани и перезапусти приложение. Строки станут просторнее.
Это минимальная высота, а не фиксированная: текущий трек с подписью может
быть выше. Верни 72px, если компактный вариант нравится больше.

### Как работает сетка
Общее правило для .track-columns и .library-item:
  grid-template-columns: 44px minmax(0, 1fr) minmax(100px, .5fr) 64px 44px;
Пять колонок: запуск/номер, название, альбом, время, меню.
minmax(0, 1fr) позволяет названию сжиматься, не расширяя окно.
Шапка и строки должны использовать одинаковую сетку.
Медиа-запросы ниже меняют её для маленьких окон.

Обложки песен в этом этапе не извлекаются. Следующий этап — собственные
изображения для обложек плейлистов. Настройки темы/обоев пока остаются планом.
