# Отчёт проверки Slynor 22

## Среда и границы

Linux, Python 3.13, headless Chromium через Playwright. Исходная база — новый
пользовательский OwnPlayerMusic.zip с SVG и WebP, не архив прошлого этапа.
Проверялись исходники. Windows EXE/установщик и Android APK не собирались.

## Автоматические результаты

- **273 Python unittest — OK.** Прежние регрессии и новые проверки: настройка
  экрана песни (миграция, типы, сохранение), целостность знаков/масок/ICO,
  первый Play без излишнего Stop, смена трека, ограничение буфера локальными
  файлами, метрики запуска без путей/URL, сохранение таймингов при Resume,
  вызов генератора app.ico перед упаковкой. Аудиотесты используют VLC doubles.
- **268 UI assertions — PASS.** API и desktop bridge контролируются фикстурами,
  анимации и раскладка выполняются настоящим Chromium. Включены прежние
  сценарии очереди, гонок метаданных, поиска и восстановления, новые восемь
  знаков, загрузка масок, пауза движения при native hide, палитра песни,
  сохранение/отключение экрана, круговой переход, reduced-motion, размеры
  мини-иконок и смена Play/Pause. Новых ошибок JavaScript не обнаружено.
- **169 layout assertions — PASS.** Четыре ширины: 1280/1000/900/390px,
  три темы: тёмная/светлая/полупрозрачная, главная/библиотека/настройки/песня,
  все три вкладки настроек. Горизонтального выхода интерактивных элементов
  за viewport нет; обложка и сетка знаков помещаются.
- Реальный локальный VP9/WebM: три цикла, без повторной установки того же URL,
  остановка/возобновление на hidden/reduced-motion. Измеренные интервалы кадров
  на границе циклов: 33/67/67 мс (89 кадров, три цикла); это не гарантия zero-gap
  для любого пользовательского файла и WebView2.
- `node --check` для всех frontend JS, Python compileall для backend/player/
  desktop и генераторов — без ошибок; pip check — без конфликтов зависимостей.

## Найденное и исправленное при проверке

- Отсутствующие SVG исходного знака вызывали буквенную заглушку. Внедрены
  истинные alpha-маски; экспорт всех восьми стилей декодируется.
- Grayscale-маска в раннем рабочем рендере давала квадраты: заменена RGBA
  с альфа-каналом 0–255; добавлен регрессионный тест.
- `scrollIntoView` пункта кастомного select прокручивал внешнюю область и
  отложенным scroll закрывал меню. Скролл теперь ограничен самим меню;
  внешний скролл перепозиционирует popup, фокус сохраняется на combobox.
  Клавиатурный выбор проверяется после отложенного события, не только сразу.
- Уточнены интервалы между label/select/Save и кнопками диагностики.
- Тест завершения reveal ждёт фактическое окончание эффекта, а не предполагает,
  что wall-clock таймаут гарантирует нужное число кадров под нагрузкой.

## Визуальная проверка

Отдельно просмотрены отрендеренные экраны: восемь знаков, главная, библиотека,
Now Playing, миниплеер, общие/визуальные/технические настройки, светлая тема,
узкие настройки/стили/экран песни, EQ на 900px. Исправленные состояния
перерисованы и просмотрены повторно. Фирменный знак взят из предоставленного
силуэта; тестовая цветная обложка — намеренная фикстура трёх цветов, не новый
дизайн пользовательского контента. Скриншоты тестов не включаются в дистрибутив.

## Не доказано этими тестами

- Слышимая задержка, треск/стабильность LibVLC на реальных дисках и устройствах.
  Метрики AudioEngine не измеряют звук на динамиках и не включают подготовку
  интернет-источника до AudioEngine. Буфер 150ms требует прослушивания Windows.
- Нативные high-DPI/WebView2/трей/значок EXE, install/update, подпись и SmartScreen.
- Работоспособность каждого провайдера в сети пользователя. UI фикстура успешной
  загрузки не является проверкой публичного сервиса или прав на загрузку.
- Android: есть архитектурный план, но нет APK, native Media3 или Android QA.
