# Этап 3: собственные обложки плейлистов

## Установка обновления
1. Полностью закрой окно приложения. Если отдельный сервер ещё работает,
   останови его через Ctrl+C. Изменён не только интерфейс, но и Python.
2. Сделай резервную копию проекта и playlists.json (при закрытом приложении).
   Данные находятся в %LOCALAPPDATA%\OwnPlayerMusic.
3. Распакуй архив обновления в существующую папку проекта с заменой файлов.
   Папки backend и frontend должны совпасть с существующими папками,
   а desktop.py — лежать рядом со start.py.
4. Не удаляй .venv и пользовательские данные.
5. В терминале VS Code из корня проекта выполни:

```bash
./.venv/Scripts/python.exe -m pip install "Pillow>=10.4,<13"
./.venv/Scripts/python.exe start.py
```

Для нового окружения полный список зависимостей находится в requirements.txt.
Уже установленный VLC остаётся необходимым; Pillow не заменяет аудиодвижок.

## Как пользоваться
1. Открой «Главная» и прокрути к карточкам плейлистов.
2. Нажми «Выбрать обложку», выбери JPG, PNG или WEBP.
3. Обложка появится на карточке и в списке плейлистов слева.
4. После выбора кнопка называется «Сменить обложку».
5. «Сбросить обложку» возвращает нейтральную заглушку.
6. Отмена диалога не меняет текущую обложку.
7. После перезапуска приложения обложка сохраняется.
8. Исходное изображение можно переместить: приложение использует свою копию.

## Ограничения и хранение
- Максимум 20 МБ и 40 млн пикселей для входного изображения.
- При импорте выполняется уменьшение до 1024×1024 без увеличения мелких
  картинок. Соотношение сторон копии сохраняется. Исходник не изменяется.
- Копия преобразуется в JPEG; прозрачность заменяется тёмным фоном.
  Поворот EXIF учитывается, метаданные изображения не переносятся.
- При отображении object-fit: cover заполняет прямоугольник карточки;
  края изображения могут не попасть в видимую область. Это не обрезка
  исходного файла. Ручной редактор кадрирования пока не добавлен.
- Копии находятся в %LOCALAPPDATA%\OwnPlayerMusic\covers\playlists.
- playlists.json содержит новое необязательное поле cover с безопасным
  сгенерированным именем. Старые плейлисты продолжают работать без него.
- Замена, сброс или удаление плейлиста удаляют ненужную старую копию обложки.
  Исходное изображение и музыка не удаляются.
- Ошибка изображения не заменяет старую обложку. При ошибке сохранения
  playlists.json новая копия удаляется, старая остаётся.
- Если сохранённая копия пропала, интерфейс показывает заглушку. Можно
  выбрать обложку заново. Не редактируй имена cover в JSON вручную.

## Что где реализовано
- desktop.py: диалог выбора, привязка копии к плейлисту, сброс и очистка.
- backend/image_assets.py: чтение/проверка/нормализация изображения,
  допустимые имена и путь к папке данных.
- backend/main.py: выдача JPEG по /api/assets/playlist-covers/{filename}.
  Этот маршрут не открывает произвольные файлы из AppData.
- frontend/js/app.js: новые кнопки и загрузка изображений с заглушкой
  при ошибке. addPlaylistCoverImage() используется для карточки и панели.
- frontend/css/styles.css: раздел 10, отображение через object-fit: cover.

## Самостоятельный эксперимент
В styles.css найди правило .playlist-cover в разделе 4:

```css
height: 108px;
```

Поменяй на 150px, сохрани и перезапусти приложение. Больше изображения
попадёт в видимую область. Ниже, в медиазапросе max-width: 560px, есть
height: 110px — это отдельная высота карточки для узкого окна.

## Обложки песен — отдельная функция
- Интернет-треки: обложка из данных официального API провайдера. Не выбираем
  случайное изображение из поиска по названию. Кэш, условия использования,
  ошибки сети и отсутствие картинки будут обработаны на этапе API.
- Локальные файлы, в том числе скачанные: встроенная обложка из метаданных
  MP3/FLAC/M4A и других поддерживаемых форматов. Не каждый файл её содержит.
- Если картинки нет или её невозможно прочитать, показываем заглушку.

На этом этапе реализованы только собственные обложки плейлистов.
Извлечение встроенных обложек песен и интернет-API пока не реализованы.
