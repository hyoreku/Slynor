## Что проверяют 21 модульный тест

- Выбор скорости до песни не вызывает `set_rate` на отсутствующем декодере.
- Во время Opening берётся последний выбранный режим.
- Три режима не вызывают play/stop/seek и не меняют позицию в имитации VLC.
- Изменение только скорости не переподключает EQ; одинаковая скорость
  повторно не применяется.
- Смена режима на паузе сохраняет паузу; resume с правильным rate не меняет rate.
- Следующий и автоматически начавшийся трек получают выбранную скорость.
- Перемотка работает в трёх режимах; устаревшая песня отклоняется.
- Старые события не меняют новую очередь; stop обезвреживает старые callbacks.
- Отказ скорости сохраняет подтверждённый режим; отказ EQ откатывает значения
  постоянного native-объекта и rate.
- Ошибка декодера видна и не молча пропускает трек.
- Новая настройка панели: defaults, миграция старого файла без перезаписи,
  сохранение остальных полей и отсутствие временного файла после записи.
- Строгий boolean; повреждённый JSON/некорректное сохранённое поле не затираются.

## Что проверяют 116 браузерных утверждений

По 29 проверок для каждого из четырёх размеров:

- Имя плейлиста как безопасный текст; карточка слева или сверху по breakpoint.
- Нет горизонтального переполнения; альбом не исчезает из строки.
- Возврат расположен в HEADER; горизонтальное предусиление справа от скорости;
  ровно 10 частот; нормальная панель помещается без внутреннего переполнения.
- Выбор скорости отправляется в API; предусиление обновляет подпись.
- Просмотр другой подборки не заменяет источник возврата текущей очереди.
- Компактная панель ровно 80 px, плейлисты/миниатюры доступны;
  фиксированная панель EQ также начинается на x=80.
- Новая подсказка переводится в EN, имя плейлиста не переводится.
- Нет сворачивания на 59-й секунде; после полного интервала оно происходит.
- Фокус в панели и открытый редактор мешают автосворачиванию;
  закрытие редактора начинает свежий интервал.
- Пауза и native minimized запрещают автосворачивание.
- Ошибка записи настройки возвращает последнее подтверждённое значение.
- Отключённое автосворачивание не срабатывает после полного eligible-интервала.

Тестовый clock ускоряет ожидание 60 секунд **только в тестах**.
Проверка геометрии использует reduced-motion для детерминированных измерений.
Изначально найденное переполнение EQ на 900×740 исправлено; полный прогон
после исправления прошёл.

## Как повторить

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для браузерных проверок отдельно нужны Node и Playwright с установленным
Chromium. Они **не требуются для работы приложения**. В среде разработки,
где Playwright доступен Node:

```bash
node tools/test_ui.cjs
```

Если браузер установлен нестандартно, задайте `CHROMIUM_PATH`.
В Linux-среде этой проверки использовался `/usr/local/bin/chromium`.
Тест создаёт снимки `tests/ui-*.png`. API полностью перехватывается локальными
fixtures; внешние сетевые запросы и пользовательская музыка не нужны.

## Что эти результаты НЕ доказывают

- Работоспособность всей программы на Windows или в собранном EXE.
- Возможность полного воспроизведения каталога ВК/SoundCloud/другого сервиса.
- «Отсутствие любых ошибок» во всех сценариях.
