# Аудит исходников перед этапом 0 и исследованием источников

> Это сохранённый аудит подготовки этапа 0. Последующие исправления обвязки msoc и исполняемый стенд описаны в [RUN_SEARCH_RU](experiment/RUN_SEARCH_RU.md).

Вход: OwnPlayerMusic_2.zip, 501841729 байт, SHA-256
`270710c7b50698cc40934a320db622e356a02ddb984fb9e36315460f2c15e31a`.
37309 элементов ZIP, суммарно 1076821737 байт после распаковки. Чтение не запускало EXE/Windows Python.
Источник истины Slynor_TZ_v0.1_RU.md найден внутри архива и прочитан.

Исходный SOURCE_SHA256.json покрывает 218 файлов; все 218 совпали до изменений. Подлинность издателя этот
неподписанный манифест не доказывает. Вложенный OwnPlayerMusic.zip содержит исторические README до этапа 22;
это не свидетельство приёмки его EXE. Оригинал и все runtime/dist сохранены отдельно от подготовленного Git.
Папки LOCALAPPDATA и реальная Windows-установка пользователя недоступны; их backup не выполнен агентом.

## Как устроена программа

| Компонент | Фактическая роль |
|---|---|
| start.py / desktop_shell.py / desktop.py | запуск, pywebview, окна/трей и хранение JSON-настроек/библиотеки |
| backend/main.py | локальный FastAPI для desktop; не публичный Music Service из ТЗ |
| player/audio_engine.py и EQ/spectrum | LibVLC и управление воспроизведением |
| backend/catalog_music.py | каталог Spotify/YouTube/SoundCloud, параллельные поиски, кеш, отдельные пулы загрузки/потока |
| backend/provider_worker.py | один JSON-запрос, фиксированные операции и HTTPS-hosts, spotDL/scdl/yt-dlp |
| backend/internet_music.py | публичные источники, Internet Archive, управление .part/загрузкой и msoc-процессом |
| backend/msoc_worker.py | hitmo/muzbomb, конечный таймаут и ограниченный ответ; отдельный Python |
| frontend/ | модульный HTML/CSS/JS и графические assets; UI не переписан |
| Slynor.spec / prepare_portable / BUILD_WINDOWS | рецепт автономной папки; Windows-доказательств в этой сессии нет |

## Что мешает считать источники и этап 0 принятыми

| Наблюдение в коде | Следствие / следующий шаг |
|---|---|
| provider_worker.download использует spotDL get_download_urls без последующей проверки artist/duration/version выбранного аудио | live/remix/cover может не совпасть; отдельный эксперимент matching и будущая проверка AudioCandidate до загрузки |
| ytdlp_rows использует artist либо uploader/channel | название канала не гарантирует исполнителя; ручная оценка карточек обязательна |
| CatalogueLibrary._catalogue_tracks проставляет download_available=True до resolve, access='prepare' | карточка не доказывает наличие полного разрешённого файла; эксперимент должен отдельно хранить availability/full/preview |
| msoc_worker возвращает title/artist/url, без duration/full/license; импорт msoc включает autodiscovery движков | проверить реальную полноту/происхождение и импорты нужных движков; изоляция процесса не заменяет аудит зависимостей |
| provider worker возвращает одну JSON-порцию | нельзя измерить первый полезный результат отдельной карточки из общего elapsed без событий; подготовить исследовательскую инструментацию |
| Существуют allowlist URL, фиксированные argv, сроки и лимиты файлов | положительная база; полной проверки redirect/DNS/вложенных manifest URL и лимитов дерева процессов для сервера ещё нет |
| В просмотренных путях запуска нет shell=True и произвольных пользовательских argv | не утверждать полный sandbox: загрузчики/нативные инструменты и будущий сервер требуют собственной ревизии |
| INSTALL.ps1/BUILD_WINDOWS/UPDATE_NETWORK ставят диапазоны/обновляют pip; BUILD очищает .buildenv и dist | воспроизводимость не принята; не запускать в оригинале; валидировать отдельные constraints в чистой копии, затем отдельное изменение сборочных рецептов |
| .venv содержит 73 пакета, включая msoc и сборочные инструменты | не брать её целиком за эталон GUI; разделённые наблюдавшиеся замыкания подготовлены из окружений |
| Полный lock, wheel hashes и lock Node/Playwright отсутствуют | сначала проверка на Windows, затем фиксация; не выдавать METADATA-снимок за готовый lock |
| Корневой LICENSE отсутствует; msoc license не удалось установить | лицензирование и распространение не приняты; см. LICENSE_REVIEW_RU.md |

Продуктовая логика backend/player/frontend в подготовке этапа 0 не менялась. Исправлены только ссылки
в START.cmd/UPDATE_NETWORK.cmd и исторической документации; новые Python-файлы относятся к аудиту состава,
а не к Telegram-боту или загрузчикам.

## Что подготовлено

- Baseline этапа 23 в локальном Git, без stable-тега/remote; подготовка этапа 0 в отдельной ветке chore/stage0.
- Ignore из раздела 14, без широкого *_backup* и без глобального игнорирования JSON/SQL/изображений.
- README/CONTRIBUTING и PowerShell-runbook с реальными путями через Read-Host, backup + hash verification.
- Исторические README_STAGE17…23 в docs/archive, ссылки исправлены; входной архив сохранён.
- GUI/provider/search/build constraints и provenance METADATA, явно observed/not validated; service — план без выдуманного lock.
- 60 запросов, матрица cold/warm × home/VPS, раздельные формы измерений/ручной оценки и лицензионный аудит.
- Read-only stage0_audit.py: категории без значений секретов; новые test-credentials не игнорируются целиком.

Аудит секретов эвристический. Семь исходных срабатываний credential URL относятся к фиктивным данным тестов;
они просмотрены и исключены только по хешам конкретных строк. Доказательство отсутствия любого возможного
секрета этим не получено; полный просмотр и поддерживаемый scanner перед push остаются обязательными.

## Не проверено

Backup и restore Windows-данных; внешняя музыка; установка из fresh Windows clone; полный unittest;
VLC/WebView2/звук/трей/мини-плеер; новый PowerShell на Windows; автономность/Setup/portable; реальные источники,
ручная релевантность, загрузки, ресурсы и доставка; домашний маршрут и VPS в РФ; права конкретных файлов;
immutable origin и лицензия msoc; выбранный musicdl provider; полнота notices релиза.

Текущая работа — подготовка и ограниченная локальная верификация. Этап 0 и эксперимент не объявляются завершёнными.
