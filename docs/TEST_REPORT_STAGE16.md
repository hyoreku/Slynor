## Живые обращения

- YouTube-поиск «Ханнамонтана»: три реальных thumbnail получены через локальный кэш и декодированы JPEG (размеры файлов 34157, 8820, 11169 байт).
- Прямой YouTube-аудиопоток: **не получен**, отказ за ~1,35 с; безопасная категория auth_required. URL и stderr в отчёт не включены. Это не успешное аудиопрослушивание.
- Spotify/spotDL: метаданные контрольной записи Kevin MacLeod — получены; подготовка MP3 **неуспешна** за ~11,12 с, spotDL не вернул файл, категория extractor. Это эвристическая категория по сообщениям, не доказательство одной точной причины всех пользовательских сбоев.

Таким образом, алгоритм быстрого запуска подтверждён тестовым ответом, а **реальное ускорение доступного потока на Windows не измерено**. Отказ источника не объявляется исправленным. Пользовательские обложки/зависания на конкретной Windows требуют повторной проверки.
