## Что проверено автоматически

Python: сохранены проверки аудиоочереди/эквалайзера этапов 11–12 с двойником VLC.
Добавлены координаты/границы окна, выбор рабочего монитора с отрицательными
координатами, возврат после отключения монитора, отсутствие нативных getter-вызовов
в обработчике движения, невозможность спрятать оба окна без трея, асинхронное
закрытие через очередь нативных команд.

Интернет: HTTPS allowlist, отказ приватным DNS-адресам и чужим редиректам,
устойчивые идентификаторы публичных потоков, сохранение закреплённых записей и
перезапуск, защита повреждённого JSON, отмена старого поиска, обработка отказа
провайдера, честный статус ВК, скрытие внутренних URL/объектов синхронизации
из JSON-ответа, локальная авторизация новых маршрутов и строгий boolean согласия.

Загрузки: отсутствие скачивания без согласия, неизвестная запись, HTML вместо
аудио, ограничение размера, повреждённый MP3, удаление `.part`. Успешный путь
проверен на **сгенерированном синусе 0.15 секунды**: ответ HTTP подменён,
валидатор mutagen и запись/атомарное переименование файла настоящие.
Это не тест настоящего скачивания полной пользовательской песни.

Браузер: ширина/анимация левой панели, обложки очереди и её появление/закрытие,
повторный клик и reduced-motion, возврат к списку, сохранение контекста плейлиста,
эквалайзер на четырёх размерах, анимации ⋯ и сведений о файле, fade кнопки запуска,
запуск по названию ровно один раз, положение кнопки миниплеера, извлечение трёх
цветов, hover scale/glow/возврат обложки, отступ формы перед карточками,
свечение плейлиста, три движущихся цветных слоя и остановка на паузе/скрытии/
reduced-motion, поиск без кнопки, группировка имён исполнителей, недоступные
SoundCloud-записи, импорт без потери этих записей, сохранение настройки трея,
управление общей моделью плеера из миниплеера, добавление потоковой ссылки и
загруженного пути через тестовый pywebview-мост.

Во время проверки обнаружен и исправлен реальный UI-дефект: фоновое добавление
скачанной песни использовало функцию локального импорта и переключало экран
на «Моя музыка». Новый параметр `navigate:false` оставляет текущий экран.

## Чего этот отчёт НЕ доказывает

Среда — Linux, Python 3.13, headless Chromium. HTTP/native API браузерных тестов
подменены. LibVLC и pywebview в Python-тестах — двойники.

Не выполнены: настоящий WebView2/WinForms/pystray, звук из устройства Windows,
реальный SoundCloud-аккаунт и ключи, интеграция ВК, приватный импорт,
перетаскивание по настоящим мониторам Windows, mixed DPI, длительный прогон,
RAM/GPU/CPU, полная загрузка и прослушивание пользовательской песни из сети.

**Нельзя объявлять устранёнными все зависания, слышимые паузы скорости и задержку EQ.**
Убраны конкретные риски блокировки GUI и добавлена диагностика. Для оставшихся
сбоев нужны логи `%LOCALAPPDATA%\OwnPlayerMusic\logs` и Windows-приёмка из
`STAGE13_FIXES_SEARCH_AND_DIAGNOSTICS.md`.

## Повторение

Python: установленные requirements + `python -m unittest discover -s tests -v`.
Браузер: Node, Playwright и Chromium (не входят в runtime приложения):

```bash
CHROMIUM_PATH=/path/to/chromium node tools/test_ui.cjs
CHROMIUM_PATH=/path/to/chromium node tools/test_stage13_ui.cjs
```

На Windows задайте `CHROMIUM_PATH` обычным способом PowerShell либо используйте
браузер, установленный Playwright. PNG снимки тестов не включены в исходный архив;
при запуске они создаются заново и не содержат настоящую пользовательскую музыку.
