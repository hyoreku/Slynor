# Фон обложки, настоящий спектр и компактный плеер

## Установка поверх предыдущего этапа
1. Закрой окно приложения и останови старый сервер.
2. Сохрани резервную копию исходников. Замени файлы проекта файлами из архива.
   Не удаляй `.venv` и `%LOCALAPPDATA%\OwnPlayerMusic`: там музыка в списках,
   плейлисты, настройки и управляемые копии изображений.
3. Из корня проекта установи две новые зависимости в существующее окружение:

```bash
./.venv/Scripts/python.exe -m pip install "numpy>=1.26,<3" "av>=14,<19"
./.venv/Scripts/python.exe start.py
```

Нужны прежние зависимости и установленный 64-битный VLC. Колёса PyAV для
64-битного Windows включают библиотеки FFmpeg: отдельный ffmpeg.exe для этого
этапа не требуется. Если pip предлагает собирать PyAV из исходников, проверь
разрядность/версию Python и pip, а не начинай установку компилятора наугад.
Для твоего Python 3.12 x64 предусмотрено готовое колесо.

## Где включать эффекты
Настройки → «Фон обложки и спектр».
- Фон из обложки **включён по умолчанию**.
- Спектроанализатор **выключен по умолчанию**, включи его для проверки.
- Переключатели дают предпросмотр. «Сохранить эффекты экрана» сохраняет оба
  значения после перезапуска, отдельно от цвета, обоев и формы плейлистов.
- Старый settings.json получает значения по умолчанию. Повреждённый файл
  не перезаписывается автоматически.

## Как работает фон
Только в «Сейчас играет» за обложкой появляется размытая копия изображения.
JavaScript дополнительно получает три частых достаточно различающихся цвета
из уменьшенной картинки и создаёт мягкие градиенты. Затемнение сохраняет
читаемость. Это простой алгоритм RGB-кластеров, не внешняя библиотека.

Отключение эффекта или отсутствие/ошибка обложки возвращает пользовательские
обои либо обычный тёмный фон. На Главной, в библиотеке и настройках цветной
фон обложки не применяется. Локальные картинки берутся из метаданных; поиск
обложек в интернете здесь ещё не добавлен — он остаётся частью этапа API.

## Что значит «настоящий спектр»
Это не случайные высоты и не таймерная имитация. Сервер декодирует короткое
окно **текущего локального файла** возле позиции VLC и вычисляет FFT:
- моно, 22 050 Гц, окно Ханна, 4096 сэмплов;
- 48 логарифмических полос от 50 Гц до 10 кГц;
- амплитуда по шкале −75…0 dBFS, сглаживание подъёма и спада в интерфейсе.

Музыку по-прежнему воспроизводит VLC. Спектр не захватывает микрофон и
системный выход; не запускает второе воспроизведение. Это анализ источника,
синхронизированный с VLC, **не измерение сигнала после звуковой карты или
будущего эквалайзера**. Громкость учитывается приблизительным коэффициентом.
Небольшая задержка возможна из-за декодирования и опроса; точность аппаратного
аудиоанализатора не обещается. Интернет-потоки в этот этап не включены.

Чтение идёт отдельным потоком с небольшим буфером, без загрузки целой песни
в RAM и без WAV-копий. При обычном воспроизведении декодер движется вперёд;
при перемотке переходит к новой позиции. Спектр активен только на экране
песни, когда включён переключатель и вкладка видима. На паузе полосы плавно
спадают; опрос прекращается. При уходе с экрана, выключении эффекта и Stop
canvas очищается, чтение файла прекращается после короткого простоя.
Ошибка анализа не останавливает музыку. Если зависимости отсутствуют,
появится сообщение; остальная часть приложения продолжает работать.

## Оформление и управление
- «Сейчас играет» не прокручивается: размер обложки учитывает доступную
  высоту; в низком окне обложка располагается слева от подписи.
- Прочие области имеют тонкие скроллбары в цветах приложения.
- Нижний плеер немного ниже. Кнопки выглядят меньше, но область нажатия
  сохранена. Пауза не скрывает панель; Stop снимает песню и скрывает её.
- Полосы громкости и времени без светлой обводки. Кружки появляются при
  наведении, взаимодействии и клавиатурном фокусе. Громкость меняется сразу.
- Выбранная песня подсвечивается градиентом акцента в прозрачность, без
  светлой вертикальной полосы.
- Обложки плейлистов немного увеличиваются при наведении. Между разделами
  короткий переход. При системном «уменьшении движения» эти эффекты отключены.
- Обычные подтверждения команд скрыты на экране песни: состояние уже видно
  под названием. Ошибки остаются отдельным уведомлением.

## Где менять код самостоятельно
- `frontend/css/styles.css`, разделы 18–22: скроллбары, маленький плеер,
  полосы, анимации, градиент строки, фон/спектр и адаптация экрана песни.
- `frontend/js/visuals.js`: 1 — настройки, 2 — цвета обложки, 3 — размеры
  и полосы, 4 — опрос и отрисовка спектра. Комментарии отмечают блоки.
- `frontend/js/app.js`: основное управление и вызовы `window.playerVisuals`.
- `frontend/index.html`: два фоновых слоя, canvas, переключатели настроек.
- `player/spectrum.py`: декодирование аудио, FFT и рабочий поток.
- `backend/main.py`: `/api/player/spectrum`, создание/закрытие анализатора.
- `desktop.py`: `save_visual_effects` и проверка boolean-полей settings.json.

React не добавлен. Для этих анимаций хватает CSS, canvas и обычного JavaScript.

## Быстрая проверка на твоём Windows
1. Запусти трек с обложкой: экран песни без прокрутки, мягкий цветной фон.
2. Выключи фон: должны вернуться свои обои; включи и сохрани.
3. Включи спектр, сохрани, вернись к песне: полосы реагируют на звучание.
4. Пауза → спад; Продолжить → реакция; перемотка → новый участок песни.
5. Перейди в библиотеку: спектр не работает в фоне; вернись через нижнюю обложку.
6. Проверь громкость, наведение на полосы, клавиши стрелок и Tab.
7. Stop → нет панели и спектра. После перезапуска настройки сохранились.

В среде разработки проверены вычисления на настоящих WAV/MP3/FLAC/M4A/Ogg,
перемотка, тишина, смена файлов, ошибки и закрытие потока; браузерный интерфейс
проверяется с тестовым мостом вместо Windows/PyWebView. Итоговый звук и
производительность именно твоего Windows/VLC нужно проверить этими шагами.
