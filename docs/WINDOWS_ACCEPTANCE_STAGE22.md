# Приёмка Slynor 22 на Windows

Это ручные проверки, ещё не выполненные на реальном Windows-компьютере.
Автотесты Linux/Chromium не заменяют WebView2, LibVLC, устройства и системный трей.
Перед обновлением сохраните проект и `%LOCALAPPDATA%\OwnPlayerMusic`.

## Запуск и сохранность

- [ ] Windows 10/11 x64, `START.cmd`: нет второго окна/фатальной ошибки; библиотека,
  плейлисты, обои, акцент, язык и прежние настройки сохранены.
- [ ] Обычное закрытие уходит в трей, если опция включена; выход через трей полностью
  закрывает процесс. Миниплеер открывается/закрывается без остановки аудио.
- [ ] После перезапуска сохраняются выбранный стиль знака и настройка экрана песни.

## Все восемь пунктов обновления

1. **Знак:** Настройки → Оформление → Значок в боковой панели. Переключить все
   восемь вариантов. Во всех узнаётся исходный силуэт, а не квадрат/буква S.
   Акцент следует выбранному цвету; стиль песни получает три цвета обложки,
   без обложки — запасную палитру. Лава смешивает пятна. Наведение/уход плавные.
2. **Иконки:** главная навигация, очередь, список, эквалайзер, поиск, миниплеер.
   Один значок на кнопку, без исходного SVG размером 512px. Миниплеер 14–16px,
   кнопки 28px; главный транспорт 19–20px, кнопки 44px.
3. **Фон:** включить цвета обложки, сравнить разные песни. Движение плавное и
   непрерывное, не мигание/резкий hue-rotate. Проверить паузу, сворачивание,
   восстановление окна и системное уменьшение движения; нет лишней нагрузки
   скрытого окна. Обои/GIF/видео и их затемнение продолжают работать.
4. **Переход:** запустить песню, открыть обложку. Круг быстро раскрывается от
   центра, не задерживая Play. Быстро сменить экран во время раскрытия:
   нет оставшегося clip-path/обрезанного интерфейса.
5. **Отключение:** Общие → Экран текущей песни. Снять флажок; локальные и
   интернет-треки играют, но экран песни не открывается, обложка не переводит
   на него. Очередь/нижний плеер доступны. Перезапуск сохраняет выбор.
6. **Аудио:** реальные WAV/MP3/FLAC с локального SSD и медленного диска;
   первый Play, Next, быстрые Next×10, Pause/Resume, Seek, смена устройства,
   локальный → интернет → локальный. Нет треска, смешения старых событий,
   повторного старта или тишины. Проверить достаточность file-caching=150ms.
   В технических настройках записать показатели «Открытие аудио», действие
   и источник при задержке. Они измеряют команду/событие VLC, не слышимый звук;
   отдельно измерить интервал до аудиовыхода. Интернет-подготовка до AudioEngine
   в эти показатели не входит.
7. **Play/Pause:** плавная смена в обоих окнах только при смене состояния,
   без пульсации каждую секунду опроса. Reduced-motion убирает анимацию.
8. **Приложение/трей:** сборка через BUILD_WINDOWS.ps1 встраивает app.ico,
   созданный из logo.png. Tray использует прежний tray.png независимо.
   Уже собранный EXE надо пересобрать; кеш значков Windows может обновляться
   не сразу. Проверить окно, EXE, ярлык и трей отдельно.

## Modern UI и регрессии

- [ ] 100%, 125%, 150%, 200% DPI: нет наложений и вырезанных кнопок; масштаб
  тестируется в WebView2, а не только изменением ширины Chromium.
- [ ] Тёмная/светлая/полупрозрачная темы; окно 1280, 1000, 900px; длинные
  названия; пустая библиотека; 10 полос EQ; активные/ошибочные состояния.
- [ ] Узкое окно: вкладки переносятся, знак выбирается в двух колонках,
  главные действия не пропадают. Это адаптивность UI, не готовая Android-версия.
- [ ] Tab/Shift+Tab, Enter, Escape, стрелки, Home/End: выбор плейлиста,
  цвета/темы, устройств. Меню не исчезает от отложенного scroll-события.
- [ ] Поиск, легально доступный поток, разрешённая загрузка, ошибка источника,
  отмена, повтор. Не предполагать доступность провайдера по синтетическому тесту.

Сохранять диагностику без паролей, токенов и приватных ссылок. Новые сетевые
провайдеры и Android APK в этот этап не входят: см. ANDROID_ROADMAP.md.
