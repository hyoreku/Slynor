# Приёмка Slynor на Windows — следующий этап плана

Автотесты не подтверждают слышимый звук, реальные устройства, отсутствие всех
зависаний или работу установщика. Ниже — воспроизводимые сценарии, а не
утверждение, что они уже пройдены. Для них не требуется аренда сервера.

## 1. Проверка окружения

Закрыть Slynor, запустить CHECK.cmd из текущего проекта. Проверить
runtime-check.json. null — пакет отсутствует; native_timeout — процесс проверки
VLC не ответил за 15 секунд. native_failed — создание/опрос VLC не завершились.
Утилита ничего не переустанавливает. Список устройств без отдельных выходов
возможен при рабочем системном выходе по умолчанию.

## 2. Звук и выходы

- Запустить локальный MP3; проверить паузу, продолжение, перемотку и переход далее.
- Выбрать доступные наушники/динамики в Технических настройках и подтвердить
  слышимое переключение. Проверить возврат к выходу Windows по умолчанию.
- Проверить смену Standard/Speedup/Slowed, затем EQ-пресета во время песни,
  на паузе и перед переходом к следующему треку. Позиция не должна сбрасываться.
  Отдельно отметить слышимый разрыв: автоматический тест не может его услышать.
- При отключении USB-устройства проверить понятную ошибку/возврат к системному
  устройству; не считать само наличие команды выбора доказательством звука.

## 3. Стабильность окна и оформления

- Обычное окно и развёрнутое → миниплеер → возврат. Повторить 10 раз.
- Во время сворачивания левой панели изменить размер основного окна.
- Поставить песню на паузу: цветные пятна продолжают движение без скачка.
- Скрыть в трей и вернуть: декоративная анимация продолжается с прежней фазы.
- Проверить настройки поверх фото/GIF/видео в тёмной, светлой и прозрачной темах:
  вкладки перекрывают прокрученный текст.
- Кнопка Стоп снимает текущий трек; скрытие цветного слоя после этого ожидаемо.

## 4. Если воспроизведётся зависание

Записать последнее действие и приблизительное время. Если интерфейс отвечает:
Технические → Сохранить снимок диагностики. Логи:
%LOCALAPPDATA%\OwnPlayerMusic\logs. Для внезапного завершения дополнительно
понадобится запись Windows «Просмотр событий → Журналы Windows → Приложение»
за нужное время, с именем сбойного модуля. Ключи, cookies и сетевые пароли
не включать. Ручной снимок стеков сам по себе не доказывает взаимную блокировку.

## 5. Установщик — после приёмки исходников

На Windows x64 выполнить рецепт docs/BUILD_WINDOWS.md, затем проверить установку
под обычной учётной записью, ярлык, закрытие в трей, удаление без потери личной
библиотеки и повторное обновление. Подпись требует сертификата Code Signing.
Скрипт сборки не равен проверенному/подписанному дистрибутиву.
Серверный доступ к музыке остаётся отложенной задачей.
