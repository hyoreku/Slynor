# Проверка этапа 15

## Автоматические результаты

- `python -m unittest discover -s tests`: **158 тестов — OK**. Используются двойники VLC/pywebview, не реальные Windows-устройства.
- `node tools/test_ui.cjs`: **116 проверок — PASS** на 1920×1080, 1280×800, 1000×800 и 900×740, без ошибок JS. API и native bridge — тестовые.
- `node tools/test_stage15_ui.cjs`: **95 проверок — PASS**. Включает предыдущие сценарии этапа 14, новые вкладки, аудиовыход, миниплеер 360×112, синхронизацию акцента/светлой темы, три режима фона, остановку движения/видео при скрытии, настройки reduced motion, совпадение координат и файлов иконок до/после сворачивания. Настоящий Chromium, но не Windows WebView2.
- Python compileall и `node --check` для всех frontend/js — PASS.

Новые unit-тесты проверяют: сохранение GIF без превращения в JPEG; лимиты и повреждённые файлы; разрешённые имена/расширения; неподдерживаемое видео/отсутствующий ffprobe; отделение обоев от статических обложек плейлистов; сохранение настроек; перечисление/освобождение списка аудиоустройств; выбор без stop/play/перемотки; валидацию API; снимок оформления; локальный кэш JPEG, доверенные CDN, отказ на private DNS/чужом redirect/повреждённом изображении; независимость происхождения аудио и обложки; русское/латинское написание артиста; PNG трея и fallback.

В журнале есть предупреждение Starlette об используемом тестовым клиентом httpx. Это не ошибка прогона. Сам установщик дополнительно запускает `pip check` обоих окружений, но PowerShell/winget в этой Linux-среде не выполнялись.

## Живые проверки с сетью и FFmpeg

1. Поиск `Kevin MacLeod Monkeys Spinning Monkeys` через установленный spotDL: **12 результатов Spotify**. Две реальные обложки прошли путь CDN → локальный JPEG-кэш; Pillow декодировал обе, 300×300.
2. Сопоставление публичной записи `Ханнамонтана / Пошлая Молли` со Spotify: **совпадение найдено** после исправления транслитерации `Poshlaya Molly`. Обложка Spotify реально получена и декодирована как JPEG 300×300; источник аудио остался `muzbomb`, не подменён Spotify.
3. Создан локальный тестовый WebM VP9 160×90, 1 секунда. **Настоящий ffprobe** проверил файл, импорт обоев скопировал его. `tools/check_video.cjs` подтвердил реальное декодирование и воспроизведение muted/loop в headless Chromium. Обработчики видимости в самом интерфейсе проверены отдельным UI-набором.
4. Скриншот миниплеера проверен визуально: светлая тема, оранжевый акцент, все кнопки, текущие метаданные; высота 112 px без прокрутки. Скриншоты тестов в поставляемый исходный архив не включены.

Для воспроизведения Node-проверок нужны Node, пакет playwright и Chromium. `CHROMIUM_PATH` может указывать на установленный Chromium. Дополнительная проверка своего локального видео: `node tools/check_video.cjs path/to/short.webm`.

## Что не подтверждено

- Установка через PowerShell/winget и запуск всех runtime на Windows.
- Нативная маршрутизация на Realtek/USB/виртуальные устройства, слышимый звук, работа на нескольких мониторах/DPI.
- Все сценарии tray/fullscreen/maximized и возврата в основной интерфейс на настоящей Windows.
- GIF/видео всех кодеков в Windows WebView2, ресурсный бюджет на ПК пользователя.
- Полное устранение зависаний, пауз смены скорости и задержки применения EQ.
- Успешная живая загрузка аудио через spotDL в этом этапе: в этапе 14 попытка закончилась AudioProviderError/YT-DLP download error. Логика загрузчика покрыта двойниками, но этого недостаточно для обещания рабочего скачивания любого трека.
- Доступ к ВК: не подключён. Официальный SoundCloud по-прежнему требует ключи.

Итог: исходники проходят **158 Python-тестов и 211 UI-проверок**; интернет-обложки и короткий WebM проверены реально. Нативная приёмка по docs/STAGE15.md остаётся обязательной.
