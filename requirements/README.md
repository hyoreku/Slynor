# Группы зависимостей: кандидат восстановления

Файлы `gui.txt`, `provider.txt`, `search.txt`, `build.txt` используют отдельные constraints.
Исходно версии прочитаны из METADATA предоставленного архива; затем каждый набор восстановлен
в чистом Windows-окружении, а проверенные lock-файлы лежат в `validated/`.
`observed/` остаётся наблюдаемым снимком, а не lock, и не обновлением зависимостей.
SHA-256 в `observed/inventory.json` относятся к METADATA, а не к wheel.
Python в pyvenv.cfg: 3.13.15; чистый clone воспроизвёл наборы на официальном 3.13.15 x64.

| Группа | Основа | Наблюдавшиеся пакеты в замыкании |
|---|---|---:|
| GUI | .buildenv, без сборочных инструментов | 37 |
| Provider | .providers | 66 |
| Search | .search | 39 |
| Build | .buildenv | 44 |

Исходная `.venv` содержит msoc и сборочные пакеты. Она не служит шаблоном GUI.
spotDL и msoc остаются в разных процессах/окружениях. Не соединять requirements в одну установку.
Старые корневые requirements сохранены для совместимости; INSTALL.ps1/BUILD_WINDOWS.ps1 пока используют именно их и не обеспечивают полную фиксацию.
UPDATE_NETWORK.cmd обновляет зависимости вне constraints; не использовать его для проверки воспроизводимости.

В НОВОМ clone на Windows после backup проверить доступность wheel, восстановить каждую группу через
`python -m pip install -r requirements/gui.txt` (соответственно другие группы), затем `pip check`, импорты,
полный unittest и реальные Windows-сценарии. Версии системных VLC/FFmpeg/Deno/WebView2 и их SHA-256 фиксируются отдельно.
Не ставить этот набор поверх единственного рабочего окружения.

Полный разрешённый набор сохранён в `requirements/validated/` с SHA-256 артефактов, версиями
Python/pip и маркерами Windows. `INSTALL.ps1` и `BUILD_WINDOWS.ps1` ставят зависимости только
из этих файлов с `--require-hashes`; при отсутствии lock-файла скрипт останавливается.
`prepare_portable.py` сборочные зависимости не устанавливает.

Все четыре группы проверены на Windows 11 x64 (CPython 3.13.15, pip 26.2.1): [validated](validated/README.md).
Свежие venv воспроизвели observed constraints без расхождений; офлайн-установка с `--require-hashes`,
`pip check` и импорты прошли, GUI-набор дополнительно прогнал 438 тестов.
`INSTALL.ps1` в чистом clone поставил все три окружения из lock-файлов: 37/37, 66/66, 39/39 пакетов,
smoke-тест приложения прошёл.
Нативные компоненты (VLC/FFmpeg/Deno/WebView2) по-прежнему не хешированы.

Бот/сервис: [service-plan.md](service-plan.md). Его lock пока отсутствует: продуктовый код не написан,
совместимый набор не проверен. Нельзя придумывать версии aiogram/SQLAlchemy/Alembic ради заполнения lock.
