# Иконки интерфейса Slynor 22

Сохранены новые SVG из пользовательского архива. Их экспортные width/height 512
не определяют размеры в интерфейсе: SVG используются как currentColor-маски.
Не закрашивать фон SVG и не добавлять внешние ссылки/скрипты.

- `icons.js` привязывает маски к кнопкам, `icons.css` задаёт геометрию.
- Главный транспорт: 19–20px; навигация: 22px.
- Миниплеер: 14–16px внутри кнопок 28×28; его окно остаётся компактным.
- Оригинальные встроенные SVG скрываются через display:none: нет второй иконки
  поверх маски. Системные символы не задают метрики значков.
- Play/Pause — короткий fade/scale при настоящей смене состояния, без повторной
  анимации на каждом одинаковом ответе poll. Reduced-motion отключает переход.
- `down.svg` используется для возврата с экрана песни.
- Номера треков, пользовательский текст и атрибуция источника не заменяются.

`app.ico` сгенерирован из `frontend/assets/logo.png` для приложения/сборки.
`BUILD_WINDOWS.ps1` пересоздаёт его через `tools/build_app_icon.py` перед упаковкой.
На Windows pywebview получает иконку из собранного EXE, а не из start(icon=...).
`tray.png` — отдельный предоставленный значок трея, байты файла сохранены.
Восемь стилей бокового знака находятся в `../app-icons/`, они не меняют EXE и трей.
Для обновления значка EXE/панели задач нужна новая сборка и перезапуск; Windows
может сохранять старый значок в кеше. Тесты Linux не подтверждают этот native-кеш.
