# Восемь стилей знака — Slynor 22

Исходный силуэт взят из предоставленного `1.webp`, его копия — `source.webp`.
Это не шрифт и не замена логотипа буквой S.

1. Белый — чистый белый силуэт.
2. Акцент — текущий цвет интерфейса, меняется сразу с темой/акцентом.
3. Лава — три перемещающихся цветных пятна внутри силуэта, не hue-rotate радуги.
4. Пиксель — отдельная ступенчатая маска 16×16, увеличенная до 48×48.
5. Цвета песни — три главных цвета текущей обложки; кешируются, смешиваются в движении.
   Без доступной обложки используется запасная палитра, не «угаданные цвета песни».
6. Хром — неподвижный металлический градиент.
7. Неон — тонкий цветной контур.
8. Космос — звёздная фактура и сияние внутри фирменного силуэта.

`1.webp–8.webp` и `1.svg–8.svg` — статические экспорты для совместимости/просмотра.
Интерактивные варианты 2/3/5 реализованы в `settings16.js` + `modern22.css`:
поэтому их состояние в приложении отличается от статического экспорта.
`mask.png` и `pixel-mask.png` — RGBA-маски с настоящей прозрачностью (не просто
чёрно-белые непрозрачные картинки).

Выбор: Настройки → Оформление → Значок в боковой панели.
Наведите курсор или перейдите клавиатурой: знак плавно увеличивается и возвращается.
Анимация цветов при скрытом/свёрнутом окне или reduced-motion останавливается.
Невидимые превью настроек не крутятся в фоне; у IntersectionObserver снимается
наблюдение со старого элемента бренда при смене варианта.

Пересборка экспортов из source.webp: `python tools/generate_brand_assets.py`.
Силуэт оригинала 48×48; для печати/большого масштабирования нужен векторный оригинал,
новые детали из малого изображения не выдумываются.

Нативный логотип: `../logo.png` → `../icons/app.ico`. Системный трей независим:
`../icons/tray.png`, он не заменяется выбранным стилем боковой панели.
